### 2. Python SDK Implementation

```python
import os
from openai import OpenAI

# Initialize client pointing to unified gateway
client = OpenAI(
    base_url="https://gen.pollinations.ai/v1",
    api_key=os.environ.get("POLLINATIONS_API_KEY")  # Your pk_ or sk_ token
)

# Stream from 0-Pollen flagship model
response = client.chat.completions.create(
    model="openai/gpt-4o",
    messages=[
        {"role": "system", "content": "You are a software architect."},
        {"role": "user", "content": "Explain server-sent events (SSE) for LLM streaming in 3 bullet points."}
    ],
    temperature=0.7,
    max_tokens=512,
    stream=True
)

for chunk in response:
    content = chunk.choices[0].delta.content or ""
    print(content, end="", flush=True)
```

## 4. Key Gotchas & Engineering Best Practices

1. **Handling HTTP 402 and the `Retry-After` Header**:
   Free Classic requests are rate-limited per IP (1 image / 45s). When throttled, the server returns HTTP 402 with `Retry-After: 45`. Never execute tight retry loops; inspect the header to back off precisely.
2. **Watermark Removal via Free Tokens**:
   Classic images may include a subtle Pollinations watermark. Registering a free account at `enter.pollinations.ai` and passing your token generates clean, unwatermarked high-resolution exports.
3. **Frontend `pk_` vs Backend `sk_` Key Separation**:
   Never expose your secret key (`sk_`) in client-side code. Always use `pk_` in React, Vue, or Chrome extensions, which provides built-in rate-limiting protection.
4. **Earn Extra Credits via Pollen Quests**:
   Pollinations rewards community members with free credits: join the Discord server (+1 Pollen) or have a pull request merged (+5 Pollen) to continuously fund heavier model generation.
5. **Full CORS Support Everywhere**:
   Both the classic GET endpoints and the unified router `https://gen.pollinations.ai/v1` respond with `access-control-allow-origin: *`, enabling direct client-side fetch calls without running backend proxies.
