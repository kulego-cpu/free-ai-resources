# 零一万物 01.AI 正式退役：李開復チームの戦略転換と2026年クレカ不要代替ガイド

中国オープンソース大規模モデル界でYiシリーズにより世界的な評価を獲得したAIユニコーン **零一万物（01.AI / 創新工場）** の一般開発者向け公開APIプラットフォームが、正式にサービス終了・退役（Fully Retired）しました。

実測検証により以下の事実が確認されています：
- ❌ **APIドメイン無効化**：`api.01.ai` のDNS名前解決が解除；
- ❌ **エンドポイント完全停止**：`api.lingyiwanwu.com` サーバーが `HTTP 410 Gone`（リソースの恒久的な削除）を明確に返却；
- ❌ **コンソール受付終了**：`platform.lingyiwanwu.com` は新規ユーザー登録およびチャージを停止し、サービス調整のお知らせを掲示；
- 🔄 **エンタープライズへの全面集中**：零一万物チームは法人向けカスタマイズおよびプライベートソリューションにリソースを全集中させ、一般個人向け公開APIの提供を終了しました。

公式アナウンスおよび開発者の検証記録：

| 日時 | 重要マイルストーン | 影響範囲 |
| :--- | :--- | :--- |
| **2026-08-03** | 新規登録窓口の閉鎖、チャージ機能の停止 | 新規アカウント作成・残高チャージ不可 |
| **2026-09-03** | **API呼び出しの完全停止**、ゲートウェイ閉鎖 | 既存の全APIキーが無効化、HTTP 410返却 |

既存のアプリケーション（NextChat、Cherry Studio、ChatBox、Cursor等）で零一万物のエンドポイントを設定している場合は、直ちに呼び出しを停止し、稼働中の代替プラットフォームへ切り替えてください。
