# アリババクラウド百錬：80以上のモデルで各100万トークン無料、国内最大規模のスターター特典

中国の大規模言語モデルエコシステムにおいて、アリババが運営する**百錬（Bailian / Model Studio）**は、最高水準の基盤インフラと網羅的なモデルラインナップで定評があります。

個人開発者や導入検討チーム向けに、百錬は**業界最大規模**の無料特典を提供しています：**80以上の主要AIモデルにそれぞれ100万トークンが付与され、合計約8,000万トークンが90日間無料で利用可能です！**

対象モデルには、最新フラッグシップの `qwen3.8-max`、高スループットの `qwen3.8-flash`、万能な `qwen3.7-plus`、コード特化の `qwen3-coder-flash` に加え、百錬が公式ホストするサードパーティの最高峰モデル（`deepseek-v4.1-flash`、`kimi-k3`、`glm-5.3` 等）まで含まれます。

ただし、この手厚い特典を利用するにあたり、**2つの重大な仕様上の注意点と課金トラップ**を事前に把握しておく必要があります。

---

## 1. 8,000万無料トークンの仕組みとルール

1. **80以上のモデルで完全独立付与（枠は共有されない）**：
   各モデルに **100万トークンの無料推論枠** が個別に付与されます（非同期Embeddingの `text-embedding-async-v2` には2,000万トークン、画像生成は50枚、動画生成は50秒を付与）。`qwen3.8-max` をどれだけ消費しても、`qwen3.8-flash` の100万枠は一切減りません。
2. **90日間の独立した有効期間**：
   各モデル枠は、百錬開通日、モデル公開日、または利用申請承認日から **90日間有効** です。日付付きのスナップショットモデル（例：`qwen3.8-max-0902`）も独立した別モデルとして新規に100万枠が付与されます。
3. **メインアカウントとRAMサブアカウントで共有**：
   メインアカウントが取得した無料枠は、配下のRAMサブアカウントが発行した API Key からも利用可能です。

---

## 2. 開発者が押さえるべき4つの落とし穴 (Gotchas)

### 1. ⚠️ 最重要・課金防止：「無料枠使い切り停止」スイッチをONにする
百錬の初期設定では、**実名認証済みアカウントが無料枠の100万トークンを使い切ると、自動的に有料の従量課金モード（分単位でアカウント残高から引き落とし）へ切り替わります！**
- **対策**：百錬コンソールにアクセス -> 左側メニューの「無料額度」を開く -> **「無料額度用完即停（枠枯渇時に自動停止）」スイッチを必ずONにしてください**！
- 有効化すると、枠を使い切ったモデルは HTTP 403（エラーコード `AllocationQuota.FreeTierOnly`）を返し、意図しない自動引き落としを完全に遮断できます。

### 2. 📍 リージョン制限：無料枠は「華北2（北京）」地域限定
無料パッケージは **cn-beijing（北京）** リージョンにのみ適用されます。
- クライアント側でシンガポール（`ap-southeast-1`）や東京（`ap-northeast-1`）などの海外エンドポイントを指定すると、**無料枠が適用されず即座に有料課金されます**。
- 必ず `cn-beijing` を含む Base URL を使用してください。

### 3. 🔑 Base URL の `{WorkspaceId}` プレースホルダーの書き換え
公式の OpenAI 互換エンドポイントは以下の通りです：
`https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`
`{WorkspaceId}` の部分は、百錬コンソールの画面右上に表示される **実際のワークスペースID**（例：`ws-xxxx`）に置き換えてください。

### 4. 🌐 利用範囲とネットワーク
- **無料枠はリアルタイム推論のみ対象**です。Batch呼び出し、ファインチューニング、専有インスタンス、OSSストレージは対象外となります。
- APIゲートウェイはブラウザのCORSを許可していないため、デスクトップアプリ（NextChat、ChatBox等）またはバックエンド経由で中継してください。

## 3. 3ステップ開通・クライアント設定手順

### ステップ 1：百錬コンソールを開通
公式コンソール直通リンクにアクセス：
👉 [https://bailian.console.aliyun.com/](https://bailian.console.aliyun.com/)
アリババアカウントまたはAlipayで実名認証を完了して開通すると、80以上のモデルの無料枠が即座に付与されます。

### ステップ 2：「使い切り停止」をONにして API Key を発行
1. コンソール左側の「無料額度」ページで **「無料額度用完即停」** を有効化します；
2. 「API-KEY」ページで新規キーを作成し、`DASHSCOPE_API_KEY` をコピーします；
3. コンソール右上のナビゲーションバーから **Workspace ID** をコピーします。

### ステップ 3：OpenAI互換クライアントに設定
NextChat、ChatBox またはコード内で設定：
- **Base URL**: `https://{あなたのWorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`
- **API Key**: 取得した `DASHSCOPE_API_KEY`
- **モデル名**: `qwen3.8-max` または `qwen3.8-flash`
- **接続テスト**: FreeAI Dogのデバッグツールでレイテンシを直接テスト可能（北京ノードで約120msの高速レスポンス）！
