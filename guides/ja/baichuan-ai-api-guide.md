# 百川知能 Baichuan AI 実践ガイド：80元無料クーポン（約500万トークン）・医療特化モデル・5 RPM制限対策

元Sogou（搜狗）CEOの王小川氏によって設立された **百川知能（Baichuan AI）** は、中国の基底モデル領域における代表的なリーディングカンパニーの1つです。検索エンジン開発や知識グラフで培われた技術力を基盤に、優れた中国語ニュアンス理解と長文推論能力を誇り、とりわけ**臨床医療特化モデル（Baichuan-M3 Plus）**においては業界随一の専門性を確立しています。

個人開発者や研究機関にとって、百川知能のオープンプラットフォームは極めて導入障壁の低い無料検証枠を提供しています：
- ❌ **海外クレジットカードや銀行口座の登録は一切不要**
- ❌ **メールアドレス登録のみで即利用可能（携帯番号や中国身分証明書の登録不要）**
- ✅ **新規アカウント登録で80元（約1,600円分）の無料クーポンを即時付与**
- ✅ **超低コストモデル「Baichuan4-Air」なら100万トークンあたりわずか0.98元（約20円）**
- ✅ **臨床・医療問診に特化した最高峰モデル「Baichuan-M3 Plus」が利用可能**
- ✅ **完全なOpenAI SDK仕様互換（エンドポイントを切り替えるだけで既存コードが動作）**
- 🟢 **完全前払い制：残高枯渇時はHTTP 402で安全停止し、意図せぬ自動課金リスクは皆無**

本記事では、百川知能の無料枠ポリシー、主力モデルの特徴、CORSの挙動、および実務導入で直面する5大注意点を詳しく解説します。

## 1. 無料枠の基本ポリシーと利用条件（80元クーポン）

百川知能の無料体験枠は、登録時に自動付与されるバウチャー形式となっています：

| :--- | :--- | :--- |
| **無料枠タイプ** | ✅ **`voucher`（新規登録バウチャー）** | アカウント開設時に80元のクレジットが残高に付与 |
| **無料額面** | **80元人民元（約1,600円 / $11.20 USD）** | 全てのモデルのAPI呼び出し費用に充当可能 |
| **換算トークン量** | **約5,000,000 〜 80,000,000 トークン** | Baichuan4-Air基準で約81M、混合利用で約5Mトークン |
| **有効期限** | **3ヶ月（90日間）** | 登録日から起算。期限到来後は未消化分が自動失効 |

## 2. 主力モデルの特徴と用途別おすすめ

百川知能は「超低価格」「汎用推論」「医療特化」の3つの軸でモデルを展開しています：

### 1. 超高コストパフォーマンス：`Baichuan4-Air`
- **料金水準**：1,000トークンあたり0.00098元 ＝ **100万トークンあたり0.98元（約20円）**；
- **特徴**：軽量・高速設計で、最初の1文字目が出るまでの遅延（TTFT）が極めて短い；
- **最適用途**：大量のテキスト前処理、多言語翻訳、要約生成、高頻度な自動応答。80元の無料枠があれば実質数百万回以上の呼び出しが可能です。

### 2. 汎用フラッグシップ：`Baichuan4` / `Baichuan4-Turbo`
- **特徴**：複雑な中国語表現、慣用句、論理的思考、指示追従性に特化したフラッグシップ基底モデル；
- **最適用途**：長文レポートの執筆、複雑なワークフロー、ロールプレイ対話。

### 3. 医療専門モデル：`Baichuan-M3 Plus`
- **特徴**：膨大な臨床ガイドライン、医学書、論文、電子カルテデータによってファインチューニングされた業界標準モデル；
- **最適用途**：ヘルスケア支援アシスタント、診断補助PoC、健康診断結果の要約解説。

## 3. クイックスタート実装（OpenAI SDK互換）

OpenAI互換プロトコルを採用しているため、既存のOpenAI SDKの `baseURL` を差し替えるだけで即座に稼働します。

### Python 実装例

```python
from openai import OpenAI

client = OpenAI(
    api_key="your_baichuan_api_key_here",
    base_url="https://api.baichuan-ai.com/v1"
)

response = client.chat.completions.create(
    model="Baichuan4-Air",
    messages=[
        {"role": "system", "content": "あなたは百川知能が開発した優秀なAIアシスタントです。"},
        {"role": "user", "content": "百川知能の強みを簡潔に3つ教えてください。"}
    ],
    temperature=0.3,
    stream=True
)

for chunk in response:
    content = chunk.choices[0].delta.content or ""
    print(content, end="", flush=True)
print()
```

## 4. 開発者が注意すべき5つの落とし穴

### 1. 厳しい 5 RPM 制限（最大の注意点）
無料枠アカウントは1分あたり5リクエスト（5 RPM）に制限されています。ループ処理や並列実行を行うと即座に `HTTP 429 Too Many Requests` が発生します。
> **対策**：API呼び出しの間に最低12秒のウェイトを設けるか、指数バックオフによるリトライ処理を実装してください。

### 2. 90日間のバウチャー有効期限
登録時に付与された80元の有効期限は3ヶ月（90日）です。期限が過ぎると残高はリセットされます。
> **対策**：登録後は放置せず、早めにプロトタイプ検証を行うことをおすすめします。

### 3. Web検索プラグインの追加課金
百川知能はWeb検索拡張機能を備えていますが、検索を実行するごとに約0.03元のプラグイン利用料が加算されます。
> **対策**：純粋なLLMテスト時は検索ツールを無効にして無料枠を節約してください。

### 4. CORSのOriginエコー仕様
CORSのOPTIONSプリフライトにおいて、`access-control-allow-origin: *` ではなくリクエストされたOriginをそのまま返すエコー方式となっています。
> **対策**：ブラウザから直接叩く場合は適切なOriginヘッダーを送信するか、バックエンドプロキシを経由してください。

### 5. 安全な前払い制（クレジットカード不要）
残高がなくなるとAPIはHTTP 402を返して終了します。クレジットカードを登録していないため、意図しない自動引き落としが発生する危険性はゼロです。
