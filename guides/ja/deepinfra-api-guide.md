# DeepInfra API 完全攻略ガイド：世界最安水準の従量課金（Llama 8Bが0.02ドル/1M〜）、デフォルト200高並行とCORS完全開放

オープンソース大モデルやGPUクラウド推論の分野において、**「単価が最も安く、単位コストあたりのスループットが極めて高いプラットフォーム」**として開発者から熱烈な支持を受けているのが、北米発の **DeepInfra（deepinfra.com）** です。

一般的な開発者向けサービスが無料枠で 5〜20 RPM 程度の厳格な制限を課す中、DeepInfra は「徹底的な低価格」と「エンタープライズ級の並行処理能力」に特化しています：
- 💰 **業界最安値のモデル推論レート**：Meta Llama 3.1 8B の入力価格はわずか **0.02ドル / 100万トークン**（約3円）
- ⚡ **モデルあたりデフォルト 200 並行（Concurrency）**：特別な申請なしで、1つのモデルに対して同時に200件のリクエストを実行可能（実質数千〜数万RPM相当）
- 🌐 **CORSワイルドカード（`*`）に完全対応**：OPTIONSプリフライト完全通過、ブラウザWebアプリから直接通信可能
- ❌ **恒久的な無料モデル枠はなし**：クレジットカード登録または事前デポジットが必須の完全従量課金制（ただし最低チャージ額制限なし）
- 🚀 **創業支援プログラム DeepStart**：条件を満たすスタートアップに最大 **10億トークン** の無料推論枠を付与

本記事では、DeepInfra の料金体系、並行処理の計算ロジック、OpenAI SDK互換の実装、および本番運用の注意点を分かりやすく解説します。

## 3. クイックスタート実装（標準 OpenAI SDK 互換）

DeepInfra は公式に `/v1/openai` 互換エンドポイントを提供しているため、既存のコードの `baseURL` を差し替えるだけで動作します：

```python
from openai import OpenAI

# DeepInfra クライアントの初期化
client = OpenAI(
    api_key="your_deepinfra_api_key_here",
    base_url="https://api.deepinfra.com/v1/openai"
)

# 極安・高並行チャット呼び出し
response = client.chat.completions.create(
    model="meta-llama/Meta-Llama-3.1-8B-Instruct-Turbo",
    messages=[
        {"role": "system", "content": "あなたはDeepInfra上で動作する高効率アシスタントです。"},
        {"role": "user", "content": "200並行リクエストが20 RPM制限と比べてバッチ処理で有利な理由を3つ簡潔に教えてください。"}
    ],
    temperature=0.3
)

print(response.choices[0].message.content)
```

## 4. 開発者が注意すべき5つの落とし穴

### 1. 決済手段の登録なしではAPIキーが動かない
会員登録だけではAPI呼び出しができません。Dashboard の Billing 画面でクレジットカードを登録するかデポジットを入金して有効化する必要があります。

### 2. 「登録で5ドル無料」の古い情報に注意
ネット上の古い情報にある登録時無料ボーナスは現在公式保証されていません。完全にチャージ残高による従量課金制として利用計画を立ててください。

### 3. 「200並行（Concurrency）」の真価
RPM（1分あたりのリクエスト数）制限と異なり、DeepInfra は同時接続数で制限します：
- 1秒で終わる処理なら、200並行で **12,000 RPM** 相当；
- 10秒かかる長文生成でも **1,200 RPM** 相当；
- マルチエージェントやクローラーなどの大量並行タスクに圧倒的に有利です。

### 4. CORS完全開放（`*`）によるフロントエンド直接呼び出し
OPTIONSプリフライトで `access-control-allow-origin: *` を返却するため、Llama 8B（0.02ドル/1M）と組み合わせることで、Node.jsバックエンドを持たない超低コストなWebアプリを構築できます。

### 5. 創業チームは DeepStart プログラムを活用
資金調達済みのスタートアップは、[DeepStart 申請ページ](https://deepinfra.com/deepstart) から最大10億トークンの無料推論枠を申請できます。
