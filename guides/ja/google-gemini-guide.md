# なぜ Google Gemini は世界で最もお得な無料 API なのか？

無料の LLM クォータを提供する世界的テック大手の中で、Google の **Google AI Studio** は個人の開発者や学習者にとって最も寛大なプラットフォームです：

- 🎁 **1日1,500回リクエストが自動回復**：毎日深夜0時に自動リセットされ、個人の翻訳、プログラミング、日常ツールに十分な容量；
- 🧠 **100万トークン超長コンテキスト (1M Context)**：500ページ超の長編小説や分厚い技術仕様書を1回のリクエストで丸ごと入力可能；
- 💳 **クレジットカード登録一切不要**：海外クレジットカードのハードルなし。通常の Google アカウントですぐに開設可能；
- ⚡ **最新旗艦モデル Gemini 2.5 / 1.5 Flash**：初速レスポンスが極めて高速で、レイテンシは 600ms 未満。

---

## 1. 事前準備

1. 通常の Google アカウント（Gmail アドレスでOK）；
2. Google サービスに接続可能なインターネット環境。

---

## 2. API Key を取得する 3 つのステップ

### ステップ 1：Google AI Studio コンソールへアクセス
ブラウザで以下の公式リンクを開きます：
👉 [https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)

Google アカウントにログインしていない場合は画面の指示に従ってログインし、利用規約に同意します。

### ステップ 2：API キーの新規発行
コンソール画面に入ったら：
1. 左上の青い **「Create API key」** ボタンをクリック；
2. ポップアップで **「Create API key in new project」**（新規プロジェクトで作成）を選択；
3. 数秒で `AIza` から始まる専用キー文字列が即座に発行されます。

### ステップ 3：キーをコピーして保存
キーの横にある **「Copy」** アイコンをクリックしてクリップボードに保存します。

> [!IMPORTANT]
> **セキュリティに関するご注意：**
> API Key は Google Cloud におけるあなたのアカウント認証情報です。ローカルのメモ帳などに大切に保管し、GitHub や SNS など公開の場に決して掲載しないでください。

## 3. FreeAI Dog ですぐに使い始める

キーを取得したら、**FreeAI Dog のトップページ** に戻ります：
1. ツールボックス上部のメーカー選択バーで **🔵 Google Gemini** を選択；
2. コピーした `AIza...` キーを入力欄に貼り付け、**「保存」** をクリック；
3. すぐ下の **「映画コンシェルジュ」** ツールで好きな作品名やジャンルを入力すれば、Google の最新モデルによる爆速推薦を即座に体験できます！
