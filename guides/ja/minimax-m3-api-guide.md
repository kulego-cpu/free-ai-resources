# MiniMax オープンプラットフォーム：マルチモーダルの実力と優れた開発体験

中国の独自基盤モデル開発をリードする **MiniMax 開発者プラットフォーム（海螺 AI）** は、高精度な長文コンテキスト処理、自然なロールプレイ対話、超リアルな音声合成、映像レベルの動画生成まで網羅したハイエンドな総合AI基盤を提供しています。

無制限の恒久無料枠こそありませんが、新規登録した全開発者に対し**15元分の体験クーポン**（有効期限：2026年12月31日まで）が自動付与され、**20 RPMの並行リクエスト制限**のもとで約350万〜700万トークン分を完全無料で試すことができます。

---

## 1. 15元クーポンでどこまで使えるのか？

15元クーポンが開発においてどれほどのボリュームを賄えるのか、最新の従量単価から見てみましょう：

1. **`MiniMax-M2.7`（高コスパ主力モデル）**：入力単価はわずか **100万トークンあたり0.6元**。15元のクーポンで **700万トークン以上** の膨大なテキストを処理可能！
2. **`MiniMax-M3`（最上位推論・長文フラグシップ）**：1Mの大容量コンテキストを誇り、複雑な論理推論や高度なマルチターン対話で業界最高水準の回答精度を発揮。
3. **`speech-2.8-hd` / `turbo`（超リアル音声合成）**：1,000文字あたりわずか0.2元で、最大 **7.5万文字分** の感情豊かな高品質音声を合成可能。
4. **`MiniMax-H3`（映像級動画生成）**：768P/2Kの高精細テキスト/画像からの動画生成に対応。

**2026年12月31日まで**、この15元クーポン（`sign_up_gift`）で上記すべてのモデルを自由に検証できます。

---

## 2. 開発前に知っておくべき4つの重要注意点 (Gotchas)

1. **⚠️ 恒久無料枠なし**：すべてのモデルが従量課金対象です。クーポンを使い切ると残高不足エラーとなるため、クライアント側で最大出力トークン数を適切に設定しておくことを推奨します。
2. **🛑 音楽生成API（Music API）は提供終了**：2026年8月20日以降、音楽生成APIは新規開発者向け提供を停止しました。新規プロジェクトでは音楽機能を利用できません。
3. **🔒 音声認識（STT）はチャージ実績が必要**：音声合成（TTS）はクーポンで利用可能ですが、音声認識（Speech-to-Text）はアカウントへのチャージ実績が必要です。
4. **🔌 OpenAI & Claude SDK にネイティブ互換**：Base URL `https://api.minimaxi.com` は、OpenAI形式（`/v1/chat/completions`）と Anthropic Claude形式（`/v1/messages`）の両方を直接サポートしています。

---

## 3. 3ステップで始めるセットアップ

1. **登録して15元クーポンを取得**：
   MiniMax 公式コンソールへアクセス：
   👉 [https://platform.minimax.cn/user-center/basic-information/interface-key](https://platform.minimax.cn/user-center/basic-information/interface-key)
   携帯番号のSMS認証で登録後、「費用センター - クーポン管理」で15元クーポンを確認。
2. **API Key を発行**：
   「基本情報 - インターフェースキー」より新規キー（`sk-` から始まるキー）を作成。
3. **AI クライアントに設定**：
   - **Base URL**：`https://api.minimaxi.com`
   - **API Key**：取得した `sk-xxxx`
   - **モデル名**：`MiniMax-M3` または `MiniMax-M2.7`
   - **動作テスト**：FreeAI Dog の「測活・デバッグツール」で即座に応答速度と導通をテストできます！
