# 月之暗面 Moonshot Kimi API 完全実測ガイド：国内実名で15元クーポン進呈、国際版課金仕様＆前払いゼロリスク解説

中国AI界において清華大学の楊植麟博士が率いるトップユニコーン **月之暗面（Moonshot AI）** のアシスタント **Kimi** は、圧倒的な超長文コンテキスト無損理解（一般アプリ版で最大200万トークン）、高精度なWeb検索統合、学術レベルの長文解析により、エンジニアや研究者から絶大な支持を集めています。

しかし、開発者向けAPIの導入にあたり、「**Kimi APIは無料で試せるのか、それとも完全有料なのか？**」「**アカウントを作ったのに残高不足エラーで呼び出せないのはなぜか？**」といった疑問や混乱が多く見られます。

2026年10月の最新実測の結果、Moonshotは極めて明確な**「国内・国際デュアルトラック運営」**を展開していることが判明しました：
- 🇨🇳 **中国国内ポータル（`platform.moonshot.cn`）**：中国本土電話番号で登録し実名認証（身分証確認）を完了すると、**15元分のAPIクーポン（約150万トークン相当）が自動付与**され、事前課金なしで直ちに `moonshot-v1` 全シリーズを呼び出せます！
- 🌐 **国際ポータル（`platform.moonshot.ai`）**：海外開発者向けの米ドル建て前払い設計となっており、**無料枠（Free Tier）は存在しません**。APIをアクティベートするには最低1ドルの初回チャージが必要です。
- 🔒 **課金リスクゼロ保証**：国内版・国際版を問わず、**純粋な完全プリペイド（Prepaid）方式**を採用。クーポンや残高が尽きるとクリーンに `HTTP 402 Payment Required` を返却するため、**クレジットカードの勝手な引き落としや高額請求のリスクは一切ありません**！

本記事では、国内ポータルと国際ポータルの仕様差、15元クーポンの対象モデル、Tier 0〜5の制限、そして5大注意事項を分かりやすく解説します。

## 2. 主要モデルの利用区分とアンロック条件

### 1. 15元クーポン対象モデル（本番レベル長文対応）
実名認証完了時に付与される15元クーポンで、以下の本番運用モデルを全額相殺できます：
- **`moonshot-v1-8k`**（入力 ¥0.012 / 1K tokens、出力 ¥0.012 / 1K tokens）：汎用対話の主力モデル。自然な日本語・中国語理解力で約125万トークンのやり取りが可能；
- **`moonshot-v1-32k`**：中長文のレポートや契約書、長編ドキュメントの抽出・要約；
- **`moonshot-v1-128k`**：最大128Kコンテキストを活用したリポジトリ全体のコード監査や学術論文の比較分析。

### 2. 現金チャージが必要なハイエンドモデル
- **`kimi-k3`**：Moonshot最新世代の推論特化型フラッグシップ。公式規約により**新規登録時の15元クーポンはK3には充当不可**と定められています。K3を利用するには、最低1回（10元または1ドル以上）の現金チャージが必要です；
- **`kimi-k2.7-code`**：プログラミング特化モデル。高精度なコード補完やアルゴリズム推論に強み。

## 3. 5大エンジニアリング注意点 (Gotchas)

### 1. ⚠️ 15元クーポンを獲得するには必ず国内版ポータルへ
GitHubやサードパーティの解説リンクから `platform.moonshot.ai`（英語の国際ポータル）に直接アクセスすると、最低1ドルの入金を要求されるため「無料枠が廃止された」と誤認しがちです。**必ず `platform.moonshot.cn`（国内ポータル）へアクセス**し、アカウント設定から身分証の実名認証を完了させてください。

### 2. ⚠️ 15元クーポンではKimi K3を呼び出せない
`kimi-k3` を呼び出した際に権限エラーや残高不足が発生しても、クーポンの有効期限切れではありません。新世代フラッグシップにはアクセス保護が設定されているためです。15元クーポンは `moonshot-v1-8k/32k/128k` に対応しています。K3をテストしたい場合はコンソールから最低10元のチャージを行ってください。

### 3. ⚠️ 無料クーポンはTier累積金額にカウントされない
Moonshot APIには Tier 0 から Tier 5 までの厳格なレート制限（RPM / TPM / 並列数）階層が設けられています。このランクアップ基準は「**実際の現金チャージ累計額**」で判定されるため、付与された15元クーポンのみを利用している期間はベースTierの保護制限が適用されます。

### 4. ⚠️ 一般向けKimiアプリと開発者APIは完全別勘定
消費者向けの `kimi.com` Web版やスマートフォンアプリ上の無料利用枠・VIP会員資格は、開発者向けAPIプラットフォームとは完全に独立しています。アプリ版の利用権をAPIトークンに変換することはできません。

### 5. ⚠️ CORSは発信元Originの正確な一致方式
`api.moonshot.cn` に対するOPTIONSプリフライトリクエストの検証結果、`access-control-allow-origin` にはワイルドカード `*` ではなく、リクエスト元となったドメインがそのままエコーバックされます。フロントエンドSPAやブラウザ拡張から直接呼び出す際はOriginヘッダーの取り扱いにご留意ください。

## 4. クイックスタート実装コード

### 1. Python (OpenAI SDK互換)

```python
import os
from openai import OpenAI

# platform.moonshot.cn で取得した sk- キーを指定
client = OpenAI(
    api_key=os.environ.get("MOONSHOT_API_KEY", "your_moonshot_api_key"),
    base_url="https://api.moonshot.cn/v1"
)

response = client.chat.completions.create(
    model="moonshot-v1-8k",
    messages=[
        {"role": "system", "content": "あなたは長文理解と的確な回答に長けたMoonshot Kimi AIです。"},
        {"role": "user", "content": "Moonshot Kimiの主な特徴を3つの箇条書きで教えてください。"}
    ],
    temperature=0.3
)

print(response.choices[0].message.content)
```

### 2. cURL コマンドによる疎通テスト

```bash
curl -X POST "https://api.moonshot.cn/v1/chat/completions" \
  -H "Authorization: Bearer $MOONSHOT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "moonshot-v1-8k",
    "messages": [{"role": "user", "content": "9.11 と 9.8 はどちらが大きいですか？"}],
    "temperature": 0.3
  }'
```
