# 2B端末Omni時代の到来：Ollama v0.40.12がLiquid AI LFM3全ファミリーをネイティブ統合

ローカルAIランタイムの標準である **Ollama** が、待望のプロダクションバージョン **v0.40.12** を正式公開しました！

今回のアップデートで最も注目を集めているのが、元MIT CSAILの研究者らが立ち上げたLiquid AIによる最新モデル群 **「LFM3（Liquid Foundation Models 3）」ファミリーの完全ネイティブ対応** です。

1.7B〜2Bクラスの極小サイズでありながら、**256Kという驚異的な超長文コンテキストウィンドウ** を持ち、音声・視覚・テキストを単一モデルで処理するOmniアーキテクチャが、コマンドライン1つで誰でも手軽に実行可能になりました。

本稿では、LFM3ファミリーのスペック、数秒で動かせる実行手順、デスクトップアシスタントとしての可能性、そして重要なハードウェア要件とライセンス条項を解説します。

---

## 1. LFM3ファミリーの全貌：Tri-hybridアーキテクチャの強み

従来のTransformerベースの小型モデルは、コンテキスト長が8K〜16Kを超えるとメモリ消費と推論遅延が二次関数的に急増する欠点を抱えていました。一方、純粋なRNNやSSM（状態空間モデル）は長文の事実照会精度においてTransformerに一歩譲ることが一般的でした。

Liquid AIの **Tri-hybrid（三元ハイブリッド計算構造）** は、畳み込み（局所特徴の高速抽出）、状態空間モデル（無限ストリーミングの低負荷処理）、線形アテンションを有機的に融合させ、わずか **1.7B〜2B** のサイズで以下の卓越したラインナップを実現しました：

| モデル識別子 | パラメータ | 主な用途 | 特徴とスペック |
| :--- | :--- | :--- | :--- |
| **`lfm3`** | 1.7B | 高速ローカルAgent基盤 | **256K長文コンテキスト**、Tool Callingおよび構造化JSON出力標準対応 |
| **`lfm3-vl`** | 約2B | 軽量ビジョンマルチモーダル | 高精細画像理解、図表解析、スクリーン認識 |
| **`lfm3-audio`** | 約2B | フルデュプレックス音声エンジン | 高精度STT＋翻訳＋18言語TTS（主要オープンソース初となるポーランド語音声対応） |
| **`lfm3-omni`** | 約2B | **テキスト＋画像＋音声を統合** | 複数モデルのパイプライン連結を廃止した超低遅延エンドツーエンド処理 |
| **`d1:2b`** | 2B | 高速インテント判定・ルーティング | ミリ秒単位での真偽・多肢選択判定特化 |

## 2. 10秒で体験：LFM3をコマンドラインで動かす

Ollama v0.40.12に更新後、以下の標準コマンドで即座に実行可能です：

### 1. 256Kコンテキスト対応のAgent基盤モデル
```bash
# 1.7B 256Kテキストモデルを実行
ollama run lfm3
```
使用メモリはわずか **約1.2GB**。大規模なソースコードリポジトリや長文ドキュメントを丸ごと読み込ませても、現代のノートPCで **80+ tokens/s** の超高速生成が可能です。

### 2. 高速ルーティングモデル `d1:2b`
マルチエージェント環境において、単純な分類タスクに70Bの大規模モデルを動かすのはリソースの無駄です：
```bash
# --ask オプションで二値分類をミリ秒判定
ollama run d1:2b "I was charged twice for order 4417." \
  --ask "Is this a billing issue?"
```
エージェントパイプラインの入口に配置することで、クエリを瞬時に振り分けることができます。

### 3. 一体型マルチモーダルOmniアシスタント
`ollama run lfm3-omni` を利用することで、スクリーンショットとマイク音声をそのまま直接モデルへ入力できます。従来の「Whisper音声認識 → LLM思考 → TTS音声合成」という3段階の伝達遅延がゼロになり、画面を見ながら滑らかに対話できるパーソナルアシスタントがローカル環境で完成します。

## 3. Ollama v0.40.12 のその他の主要な改善

LFM3以外にも、以下の重要なアップデートが含まれています：
1. **Apple Silicon高速化**：Gemma 4、Flint、Lagunaモデルのプロンプト処理性能がMシリーズチップ上で大幅に向上；
2. **DFlash2 投機的デコーディング**：MLXとの連携により、小型ドラフトモデルを併用した推論スループットが最大50%向上；
3. **OpenCode v2 対応**：`ollama launch` コマンドで最新の共同開発エコシステムをサポート；
4. **Kimi CLI バグ修正**：ツール実行のみのアシスタントターンの動作不具合を解消。

また、llama.cppのコア開発者 `tdakhran` 氏の協力により、**Zero-Day（同日即時サポート）** が達成されました。

## 4. ハードウェア要件とライセンス境界（注意点）

FreeAI Dogでは技術の客観的な制約も包み隠さずお伝えします：

1. **⚠️ 現在のハードウェア制約**：
   * v0.40.12時点では、**`lfm3` および `d1:2b` のバックエンドはApple Silicon（Mac）のみの先行サポート** となっています；
   * Linux（CUDA/ROCm）およびWindowsサポートは現在開発が進められており、近日のマイナーアップデートで順次提供予定です。

   * Liquid AIは段階的ライセンスを採用しています：**個人利用、学術研究、非営利、年間売上1,000万ドル（約15億円）未満のチームは完全無料**；
