# テンセント混元 (Hunyuan)：真の無料枠と開発者のための安全設計ガイド

テンセントクラウドの自社開発基盤モデル群である**テンセント混元（Tencent Hunyuan）**は、アジアの開発者層において広く認知されています。しかし、コミュニティ上では「混元-Liteが永久無料」といった古い情報や誤解が広まりがちです。

本記事では、2026年10月現在の公式ドキュメントと課金体系に基づき、テンセント混元の実際の無料特典、対応モデル、安全な自動課金防止策を分かりやすく整理します。

---

## 1. 誤解の解消：独立した「混元-Lite永久無料」は存在しない

「混元-Liteが永久無料で使える」という記述を目にすることがありますが、公式APIカタログを検証した結果：

1. **❌ `hunyuan-lite` という独立した汎用言語モデルは存在しません**：主力モデルは MoE 構造の `hunyuan-a13b` やロールプレイ専用の `hunyuan-role-latest` などです。
2. **唯一 lite が付くのは翻訳特化モデル**：`hunyuan-translation-lite`（入力 1元/1Mトークン）のみであり、これも有償モデルですが初期無料パックの対象に含まれています。
3. **❌ 永年無料のモデルはありません**：すべての無料枠は**開通から1年間の有効期限付きリソースパック**として提供されます。

---

## 2. 開通時に実際に付与される無料リソース

永年無料ではないものの、初期特典は十分実用的で充実しています：

1. **8モデルで共有できる 100万テキストトークン**：
   - **`hunyuan-a13b`**：MoE 構成（総80B / 活性13B）の主力モデル。224K の長文コンテキストに対応し、思考切り替え（`/no_think`）が可能。
   - **`hunyuan-role-latest`**：自然な対話と感情豊かなロールプレイに特化。
   - **`hunyuan-translation`**：33言語・5民族言語に対応した高精度翻訳（WMT25 首位）。
   - **マルチモーダル**：画像理解の `Tencent HY Vision 1.5 Instruct` など。
2. **独立した 100万トークンの Embedding パック**：`Hunyuan-embedding` セマンティック検索モデル向け。
3. **画像生成 100回分**：商用級の「混元生図」50回 ＋ 高速な「文生図軽量版」50回。

---

## 3. 最大の安心要素：使い切り後の自動課金は一切なし！

クラウドAIサービスで最も懸念されるのは、無料枠終了後にクレジットカード等へ自動で従量課金される「意図しない請求リスク」です。

テンセント混元はこの点で極めて良心的な設計を採用しています：
> **🛡️ 公式仕様**：デフォルト状態では、無料リソースパックが枯渇または有効期限切れとなった場合、**テキスト・画像ともに自動で従量課金（後払い）へ移行しません**！

残高ゼロでAPIは安全にエラー停止するため、管理画面で明示的に後払いを開通しない限り、勝手に請求が発生することはありません。

## 4. 移行状況と3ステップ利用開始手順

現在テンセントクラウドは混元モデルを次世代基盤 **TokenHub** へ統合進行中ですが、既存コンソールからのAPI呼び出しは引き続き安定してご利用いただけます。

### 3ステップ設定：

1. **ログインと実名認証**：
   混元コンソールへアクセス：
   👉 [https://console.cloud.tencent.com/hunyuan](https://console.cloud.tencent.com/hunyuan)
   WeChat または QQ でログインし、実名認証を完了（クレカ不要）。
2. **混元サービスを開通して無料枠受取**：
   管理画面で「今すぐ開通」をクリックすると、100万トークンと画像生成100回が付与されます（1年間有効）。
3. **OpenAI互換クライアントに設定**：
   - **Base URL**：`https://hunyuan.tencentcloudapi.com`
   - **API Key**：コンソールで発行した API Key
   - **モデル名**：`hunyuan-a13b`
   - **疎通確認**：FreeAI Dog の「測活・デバッグツール」で直接レイテンシを測定可能！
