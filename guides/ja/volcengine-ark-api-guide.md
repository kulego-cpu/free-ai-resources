# 火山方舟（Volcengine Ark）完全実測ガイド：各モデル50万トークン無料枠、安心体験モード課金防止＆極速レスポンス

中国のエンタープライズAIクラウドにおいて、ByteDance（バイトダンス）が展開する **火山方舟（Volcengine Ark）** は、自社開発の「豆包（Doubao）」モデルファミリー、BGPバックボーン直結の高速ネットワーク、そして極めて手頃な利用料金により、爆発的な普及を見せています。

自社製豆包シリーズに加え、火山方舟は DeepSeek-V3 / R1（フルスペック版）、智譜 GLM、月之暗面 Kimi / Moonshot などの有力オープンソース・サードパーティモデルも高品質にホストしています。開発者にとって特に魅力的なのが**極めて太っ腹で安全な無料体験設計**です：
- ❌ **海外クレジットカードの登録は一切不要**
- ✅ **対象となる 25 以上の主要モデルそれぞれに、独立して 50 万トークンの無料体験枠を付与（合計 1,250 万トークン以上の無料計算資源）**
- ✅ **業界随一の安全性を持つ「安心体験モード」：枠上限に達すると自動停止し、意図しない課金を完全排除**
- ✅ **ByteDance 自社 BGP バックボーン直結によるミリ秒級の極速レスポンス（TTFT）**
- ✅ **OpenAI 互換プロトコルに完全準拠、Python や Node.js、各種コーディングツールから直接利用可能**

本記事では、火山方舟の無料枠ポリシー、安心体験モードの仕組み、モデルラインナップ、および 5 大エンジニアリング注意点を詳細に解説します。

## 1. コアポリシーと枠構造：モデルごとに独立した 50 万トークン

火山方舟の無料枠は、全モデルで一つの少ない枠を共有するのではなく、**モデルごとに独立して 50 万トークンずつ付与**される点が大きな特徴です：

| 評価項目 | 公式規約と実測結果 | 要点と推奨事項 |
| :--- | :--- | :--- |
| **無料枠タイプ** | ✅ **`voucher`（モデル別体験パッケージ）** | 対象モデルごとに個別に 50 万トークンが付与される |
| **単一モデル枠** | **500,000 トークン / モデル** | 基底モデルおよびそのファインチューニング推論点を含む |
| **対象モデル数** | **25 以上の主要モデル** | 豆包 Pro/Lite/Vision、DeepSeek-V3/R1、GLM、Moonshot など |
| **理論上の合計枠** | **12,500,000 トークン以上** | 複数モデルを使い分けることで数ヶ月のプロトタイピングが可能 |
| **課金防止スイッチ** | 🟢 **「安心体験モード」（公式コンソール機能）** | 無料枠のみを消費し、上限到達で自動停止。課金発生リスクゼロ |
| **クレジットカード** | ❌ **完全不要** | 無料体験中はクレカや銀行口座の登録は不要 |
| **実名認証条件** | ⚠️ **必須条件** | 中国携帯電話番号と中国身分証による実名認証が必須 |
| **CORS 跨域** | ⚠️ **リクエスト元 Origin を正確に返却** | OPTIONS プリフライトで Origin をエコーバック（`*` ではない） |
| **OpenAI 互換性** | 🟢 **完全互換** | 標準エンドポイント `https://ark.cn-beijing.volces.com/api/v3` |
| **超過時の挙動** | 安全に呼出失敗を返却 | 安心体験モードでは自動的に従量課金へ移行しない |

## 2. 25+ 無料対応モデルのおすすめ

火山方舟で 50 万トークン無料枠が利用可能な主要モデル群：

### 1. 超高速レスポンス＆日常利用：豆包 Lite シリーズ
- **`doubao-1.5-lite-32k`** / **`doubao-lite-4k`**：32K コンテキスト対応、ミリ秒級で出字が始まる超高速軽量モデル。高頻度な要約や分類に最適。
- **推奨用途**：リアルタイムチャットボット、文書ルーティング、大量データの事前処理。

### 2. 複雑推論＆エンタープライズ旗艦：豆包 Pro シリーズ
- **`doubao-1.5-pro-32k`** / **`doubao-pro-128k`** / **`doubao-pro-256k`**：ByteDance の主力フラッグシップ。優れた長文理解力と複雑な指示追従性を持ち、超長文コンテキストにも対応。
- **推奨用途**：難関課題の推論、論文・長大契約書の精読、社内ナレッジベース RAG。

### 3. 公式ホストのフルスペック DeepSeek
- **`deepseek-v3`**：671B フルスペック MoE オープンモデルを ByteDance クラスタ上で高速ホスト。
- **`deepseek-r1`**：思考プロセス（Reasoning）を透明に出力する先端推論モデル。

### 4. マルチモーダル視覚：豆包 Vision
- **`doubao-1.5-vision-pro-32k`**：画像認識、図表OCR、UI解析に対応した高性能ビジョンモデル。

## 3. 実装における 5 大落とし穴 (Gotchas)

### 1. ⚠️ 「安心体験モード」が有効であることを必ず確認
火山方舟の最大の特徴が「安心体験モード」です。これをオンにしておくと、贈呈された 50 万トークン枠のみを消費し、枠が尽きると自動的に API が停止します。**予期せぬ従量課金が発生することを確実に防げる**ため、本格利用前に管理画面で有効化されているか必ず確認してください。

### 2. ⚠️ 無料枠はモデルごとに独立して計算される
50 万トークンは全モデル合算ではありません。例えば `doubao-1.5-pro-32k` で 50 万トークンを使い切っても、`doubao-1.5-lite-32k` や `deepseek-v3` にはそれぞれ未使用の 50 万トークンが残っています。モデルを切り替えながら開発することで無料期間を大幅に延ばせます。

### 3. ⚠️ 中国携帯電話番号と中国身分証による実名認証が必要
中国国内の法規制に準拠しているため、利用には中国本土の身分証明書による実名認証が求められます。中国身分証を持たない海外開発者は無料枠を有効化できません。

### 4. ⚠️ CORS はワイルドカード `*` ではなく Origin をエコーバック
OPTIONS プリフライト検証において、火山方舟ゲートウェイは `access-control-allow-origin: *` ではなく、リクエスト元の Origin（例: `https://yourdomain.com`）を正確に返却します。ブラウザからの直接呼出時はドメイン設定にご留意ください。

### 5. ⚠️ 標準モデル名と Endpoint ID の違い
火山方舟では 2 種類の model 引数指定が可能です：
- 標準プリセット名：`doubao-1.5-pro-32k`、`deepseek-v3` など；
- カスタム接続点 ID：`ep-20250101xxxxxx-xxxxx` 形式の識別子。
標準モデル名で 404 が返る場合は、管理画面で作成された接続点の Endpoint ID を指定してください。

## 4. サンプルコード

### 1. Python (OpenAI SDK 完全互換)

```python
import os
from openai import OpenAI

# console.volcengine.com/ark で取得した API Key を指定
client = OpenAI(
    api_key=os.environ.get("ARK_API_KEY", "your_volcengine_ark_api_key"),
    base_url="https://ark.cn-beijing.volces.com/api/v3"
)

response = client.chat.completions.create(
    model="doubao-1.5-pro-32k",
    messages=[
        {"role": "system", "content": "あなたは火山方舟で提供されている豆包フラッグシップモデルです。"},
        {"role": "user", "content": "火山方舟の主な強みを箇条書きで3点教えてください。"}
    ],
    temperature=0.7,
    max_tokens=512
)

print(response.choices[0].message.content)
```

### 2. cURL コマンドライン実行

```bash
curl -X POST "https://ark.cn-beijing.volces.com/api/v3/chat/completions" \
  -H "Authorization: Bearer $ARK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-1.5-lite-32k",
    "messages": [{"role": "user", "content": "開発者に向けた励ましの一言をください。"}],
    "temperature": 0.5
  }'
```
