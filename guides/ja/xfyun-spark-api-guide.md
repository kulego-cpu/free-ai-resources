# iFLYTEK Spark Lite：国内では極めて貴重な「永久無料＋無制限トークン」の基盤モデル

多くの中国系LLMベンダーが「体験ポイント贈呈（期限切れまたは枯渇後に課金が必要）」というモデルへ移行する中、科大訊飛（iFLYTEK）が提供する**訊飛星火大模型（iFLYTEK Spark）**は、個人開発者に対して驚くほど手厚い特典を提供し続けています：**主力軽量モデル Spark Lite（model: `lite`）は、公式に永久 0 元無料かつトークン総量上限なし（無制限トークン）です！**

さらに嬉しい点として、訊飛星火オープンプラットフォームの登録手続きは非常にシンプルです。**身分証による実名確認（KYC）やクレジットカードの登録は一切不要**。SMS認証コードを受け取るだけで、数秒でAPI Keyが発行されます。

## 1. 公式検証：Spark Lite は本当に「永久無料」なのか？

「永久無料」という言葉を聞くと、隠れた課金や体験期間終了後の自動引き落としを警戒する開発者も多いでしょう。

訊飞公式のAPI仕様および課金体系を徹底検証した結果は以下の通りです：
1. **公式ドキュメントで0元を明記**：Spark Lite（`lite`）は軽量汎用言語モデルとして位置づけられ、ドキュメントおよび料金表で「無料利用対応」と明記されています。Xingchen MaaSプラットフォームの課金においても微調整（Fine-tuning）のみ有料で、標準推論の単価は **¥0 / 100万トークン** です；
2. **有効期限付きクーポンではなく無制限**：毎月リセットされたり数ヶ月で失効する一時的なバウチャーとは異なり、Liteモデルの無料枠には総量の上限がありません。個人用アシスタントや自動化スクリプトの常設フォールバックモデルとして最適です；
3. **MaaSエッジ向け小型モデル特典**：プラットフォーム上ではさらに、**`Spark-X2.5-1.7B`（エッジ向け小型モデル・永久無料・100万コンテキスト）** および **`Spark-X2.5-4B`（期間限定無料）** も提供されています。

## 2. 開発者が知っておくべき 4 つの注意点 (Gotchas)

訊飛星火の無料APIを利用する際、以下の仕様上の制約に留意してください：

1. **⚡ 2 QPS の同時実行制限**：
   無料枠の主な制約は、**1アカウントあたり 2 QPS（1秒間に最大2回のリクエスト、120 RPM相当）** です。個人の対話や順次実行タスクには十分ですが、マルチスレッド等で高負荷の同時リクエストを行うとエラーコード `11202`（レートリミット超過）が即座に返されます。
2. **🌐 CORS 未対応（バックエンド中継が必要）**：
   訊飛星火のAPIゲートウェイには `Access-Control-Allow-Origin` レスポンスヘッダーが付与されていません。ブラウザのフロントエンドからネイティブな `fetch` で直接呼び出そうとすると、CORSポリシーにより遮断されます。**NextChatやChatBoxなどのデスクトップアプリから直接利用するか、Node.js / Python などのバックエンド経由で中継してください。**
3. **🛠️ Lite モデルの機能制限**：
   Liteモデルはストリーミング出力（SSE）および構造化JSON出力に対応し、コンテキストは8K入力（最大出力4K）です。ただし、**Web検索プラグインおよび Function Calling（ツール呼び出し）には非対応**です。関数呼び出しが必要な場合は有料の `4.0Ultra` フラグシップモデルをご利用ください。
4. **🔑 シンプル認証：APIPassword をそのまま Bearer Token として使用**：
   現在の訊飛は標準のOpenAIリクエスト形式に完全対応しています。従来の複雑なWebSocket HMAC-SHA256署名は不要となり、HTTPヘッダーに `Authorization: Bearer <あなたのAPIPassword>` を渡すだけで呼び出せます！

## 3. 3ステップで完了する開通・クライアント設定手順

1. **電話番号で登録してコンソールへログイン**：
   公式コンソールの直通リンクにアクセス：
   👉 [https://console.xfyun.cn/services/bmx1](https://console.xfyun.cn/services/bmx1)
   SMS認証コードを入力してログイン完了。身分証明書のアップロードや顔認証は一切不要です。
2. **アプリを作成して認証情報を取得**：
   アプリ一覧から新規アプリを作成し、「HTTP インターフェース呼び出し認証」欄から **APIPassword** をコピーします。
3. **OpenAI互換クライアントに設定**：
   - **Base URL**: `https://spark-api-open.xf-yun.com/v1`
   - **API Key**: 取得した `APIPassword`
   - **モデル名**: `lite`
   - **接続テスト**: FreeAI Dogの「接続テスト＆デバッグツール」で直接レイテンシを測定可能（通常約150msの高速レスポンス）！
