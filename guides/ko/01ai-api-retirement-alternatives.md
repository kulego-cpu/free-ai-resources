# 01.AI 개발자 플랫폼 공식 서비스 종료: 리카이푸 팀의 사업 재편 및 2026 대체 플랫폼 가이드

중국 오픈소스 대형 모델 시장에서 Yi 시리즈 모델로 글로벌 벤치마크 정상에 올랐던 AI 유니콘 **01.AI (링이완우 / 創新工場)** 의 일반 개발자용 공개 API 플랫폼이 공식적으로 서비스를 종료하고 퇴역(Fully Retired)했습니다.

실측 검증 결과 확인된 사실:
- ❌ **API 도메인 연결 해제**: `api.01.ai` DNS 이름 확인 불가;
- ❌ **엔드포인트 영구 폐쇄**: `api.lingyiwanwu.com` 서버에서 `HTTP 410 Gone` (리소스 영구 제거) 반환;
- ❌ **콘솔 접수 마감**: `platform.lingyiwanwu.com` 은 신규 회원가입 및 충전을 중단하고 서비스 조정 안내문 게시;
- 🔄 **엔터프라이즈 전면 재편**: 01.AI 팀은 기업 맞춤형 솔루션 및 프라이빗 구축 사업으로 전면 전환하여 일반 개발자 대상 공개 API는 제공하지 않습니다.

## 1. 01.AI API 서비스 종료 일정

| 일자 | 주요 마일스톤 | 영향 범위 |
| :--- | :--- | :--- |
| **2026-08-03** | 신규 회원가입 중단, 플랫폼 결제 충전창구 폐쇄 | 신규 개발자 계정 생성 및 크레딧 충전 불가 |
| **2026-09-03** | **API 호출 전면 중단**, 게이트웨이 완전 오프라인 | 기존 모든 API Key 무효화, HTTP 410 반환 |

## 2. 2026년 추천 신용카드 불필요 대체 플랫폼 5선

기존에 Yi 모델군(Yi-Lightning, Yi-Large)을 사용했던 개발자들을 위해 FreeAI Hub가 선별한 **2026년 가장 안정적인 카드 불필요 중국 직결 대체 플랫폼**입니다:

### 1. 스텝펀 (StepFun / 階躍星辰) —— 극강의 가성비 & 오디오 멀티모달
- **핵심 강점**: 전 MS 부사장 장다신 박사 창업. 자체 수천억/수조 파라미터 MoE 기반 모델.
- **주력 모델**: `step-3.5-flash` (입력 1M 토큰당 $0.10 초저가), `stepaudio-3` 시리즈 (음성/음악 4종 모델 한시적 무료 체험).
- **특화 기능**: 중국 내 매우 드문 **CORS 와일드카드(`*`) 완전 개방**으로 브라우저 프론트엔드 직접 fetch 지원.
- **진입 장벽**: 전화번호 가입 및 실명 인증으로 즉시 연동.

### 2. 바이두 첸판 (Baidu Qianfan) —— 대규모 무료 토큰 혜택
- **핵심 강점**: 가입 시 **17개 모델 각 100만 토큰(총 1,700만 토큰)** 무상 증정(모델별 3개월 유효).
- **주력 모델**: DeepSeek-R1 (풀스펙 671B), 어니 ERNIE 4.5 Turbo, Qwen3-Coder 전 시리즈.
- **호환성**: 신규 v2 인터페이스로 OpenAI SDK 표준 완벽 지원.
- **진입 장벽**: 신용카드 불필요.

### 3. 볼케이노 아크 (Volcengine Ark) —— 바이트댄스 안정적 인프라
- **핵심 강점**: 바이트댄스 공식 플랫폼. 25개 이상 모델에 **각 50만 토큰 무료 제공**(총 1,250만 토큰 이상).
- **안전 장치**: '안심 체험 모드' 스위치로 무료 한도 소진 시 트래픽을 자동 차단하여 과금 위험 제로.
- **주력 모델**: 더우바오 Doubao-1.5-pro, DeepSeek-V3 / R1 풀스펙.

### 4. 실리콘플로우 (SiliconFlow) —— 오픈소스 모델 집약 허브
- **핵심 강점**: 가입 실명 인증 시 14~16위안 바우처 지급, 20여 개 모델 상시 0원 무료 제공.
- **주력 모델**: DeepSeek-V3, DeepSeek-R1, Qwen2.5, Kolors 이미지 생성.
- **진입 장벽**: 중국 직결 초고속 네트워크, 표준 OpenAI 규격 지원.

### 5. 즈푸 BigModel (Zhipu) —— 칭화대 출신 학술 벤치마크 리더
- **핵심 강점**: GLM-4.7-Flash, GLM-4.5-Flash, CogView-3-Flash 이미지 생성 등 영구 무료 제공.
- **주력 모델**: 200K 초장문 컨텍스트와 심층 사고력을 지원하는 GLM 플래그십.
