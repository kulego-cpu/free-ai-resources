# 알리바바 백련(Bailian): 80+개 모델별 100만 토큰 무료, 국내 최대 규모의 스타터 팩

중국 파운데이션 모델 생태계에서 알리바바가 운영하는 **알리바바 백련(Model Studio / Bailian)** 은 독보적인 클라우드 인프라와 방대한 모델 라인업으로 손꼽힙니다.

개인 개발자와 도입 검토 팀을 위해, 백련은 **업계 최대 규모**의 무료 체험 패키지를 제공합니다: **80개 이상의 주요 파운데이션 모델에 대해 각 100만 토큰씩, 총 약 8,000만 토큰이 90일간 무료로 제공됩니다!**

최신 플래그십인 `qwen3.8-max`, 고처리량 경량 모델 `qwen3.8-flash`, 만능형 `qwen3.7-plus`, 코드 특화 `qwen3-coder-flash`뿐만 아니라 백련이 공식 호스팅하는 최상위 외부 모델(`deepseek-v4.1-flash`, `kimi-k3`, `glm-5.3` 등)까지 모두 포함됩니다.

그러나 이 파격적인 혜택을 이용하려면 **반드시 숙지해야 할 2가지 핵심 엔지니어링 규칙과 과금 함정**이 있습니다.

---

## 1. 8,000만 무료 토큰의 지급 및 사용 규칙

1. **80+개 모델별 독립 지급 (할당량 미공유)**:
   무료 대상 모델마다 독립적으로 **100만 토큰의 추론 할당량**이 부여됩니다 (비동기 임베딩 모델 `text-embedding-async-v2`는 2,000만 토큰, 이미지 생성은 50장, 영상 생성은 50초 지원). `qwen3.8-max`를 전량 소진하더라도 `qwen3.8-flash`의 100만 토큰에는 전혀 영향을 주지 않습니다.
2. **90일의 독립 유효기간**:
   무료 할당량은 백련 개통일, 새 모델 출시일 또는 승인일로부터 **90일간 유효**합니다. 날짜가 붙은 스냅샷 모델(예: `qwen3.8-max-0902`) 역시 독립된 별도 모델로 취급되어 새로운 100만 토큰이 제공됩니다.
3. **루트 계정과 RAM 서브 계정 공유**:
   루트 계정이 수령한 무료 혜택은 산하의 모든 RAM 서브 계정에서 발급한 API Key로도 함께 사용할 수 있습니다.

## 2. 개발자가 알아야 할 4가지 주의사항 (Gotchas)

### 1. ⚠️ 과금 차단 필수: '무료 할당량 소진 시 즉시 중단' 스위치 켜기
기본 설정 상태에서는 **실명인증을 마친 계정이 100만 토큰을 모두 쓰면, 알림 없이 즉시 분당 종량제 후불 과금 모드로 자동 전환됩니다!**
- **방지 조치**: 백련 콘솔에 접속 -> 좌측 메뉴의 '무료 할당량(免费额度)' -> **'소진 시 즉시 중단(免费额度用完即停)' 스위치를 반드시 켜두세요**!
- 스위치를 켜두면 토큰 소진 시 HTTP 403 (에러 코드 `AllocationQuota.FreeTierOnly`)이 반환되며, 예상치 못한 요금 청구를 완벽히 차단합니다.

### 2. 📍 리전 제약: 무료 혜택은 '화베이2(베이징)' 리전 전용
무료 패키지는 **cn-beijing(베이징)** 리전에 엄격히 제한됩니다.
- 클라이언트 엔드포인트에 싱가포르(`ap-southeast-1`)나 도쿄(`ap-northeast-1`) 등 해외 리전을 넣으면 **무료 혜택이 적용되지 않고 즉시 종량제 요금이 부과됩니다**!
- 반드시 `cn-beijing`이 포함된 Base URL을 사용해야 합니다.

### 3. 🔑 Base URL 내 `{WorkspaceId}` 플레이스홀더 교체
공식 OpenAI 호환 엔드포인트 형식은 다음과 같습니다:
`https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`
`{WorkspaceId}` 부분은 백련 콘솔 우측 상단에 표시되는 **실제 작업공간 ID**(예: `ws-xxxx`)로 바꿔 넣어야 정상 호출됩니다.

### 4. 🌐 사용 범위 및 CORS
- **무료 할당량은 실시간 온라인 추론에만 적용**됩니다. 배치(Batch) 호출, 파인튜닝, 전용 인스턴스 배포, OSS 스토리지 비용 등은 제외됩니다.
- 브라우저 CORS가 지원되지 않으므로 데스크톱 클라이언트(NextChat, ChatBox 등)나 Node.js / Python 백엔드 프록시를 통해 호출하세요.

## 3. 3단계 개통 및 클라이언트 연동 가이드

### 1단계: 백련 콘솔 로그인 및 플랫폼 개통
백련 공식 콘솔 링크에 접속합니다:
👉 [https://bailian.console.aliyun.com/](https://bailian.console.aliyun.com/)
알리바바 계정 또는 알리페이로 실명인증을 완료하고 개통하면 80개 이상 모델의 무료 패키지가 자동 지급됩니다.

### 2단계: '소진 시 중단' 켜기 및 API Key 생성
1. 좌측 메뉴의 **'무료 할당량'** 페이지에서 **'소진 시 즉시 중단'** 스위치를 활성화합니다;
2. **'API-KEY'** 메뉴에서 새 키를 생성하고 `DASHSCOPE_API_KEY`를 복사합니다;
3. 콘솔 우측 상단에서 **Workspace ID**를 확인하여 메모합니다.

### 3단계: OpenAI 호환 클라이언트에 설정
NextChat, ChatBox 또는 코드에 다음과 같이 설정합니다:
- **Base URL**: `https://{본인의WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`
- **API Key**: 발급받은 `DASHSCOPE_API_KEY`
- **모델명**: `qwen3.8-max` 또는 `qwen3.8-flash`
- **지연 시간 테스트**: FreeAI Dog 디버거 도구에서 직접 연결 상태를 점검해 보세요 (베이징 노드 기준 약 120ms로 매우 빠릅니다)!
