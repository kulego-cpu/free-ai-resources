# 바이촨 AI API 실전 가이드: 80위안 무료 바우처(~500만 토큰), 의료 특화 LLM 및 5 RPM 대응 전략

검색 엔진 및 지식 그래프 기술의 강자 소고우(Sogou)의 전 CEO 왕샤오촨이 설립한 **바이촨 AI(Baichuan AI)**는 중국 파운데이션 모델 시장의 핵심 플레이어 중 하나입니다. 수준 높은 중국어 텍스트 처리와 논리 추론 능력뿐 아니라, 특히 **임상 의료 특화 모델인 Baichuan-M3 Plus**를 통해 차별화된 입지를 다지고 있습니다.

글로벌 개발자와 연구진에게 바이촨 AI의 오픈 플랫폼은 매우 낮은 진입 장벽과 강력한 무료 혜택을 제공합니다:
- ❌ **해외 신용카드나 복잡한 금융 수단 불필요**
- ❌ **이메일 가입만으로 즉시 시작 (중국 전화번호나 신분증 인증 없이 바로 사용 가능)**
- ✅ **신규 가입 시 80위안(약 15,000원 상당) API 바우처 즉시 지급**
- ✅ **초저비용 모델 Baichuan4-Air 사용 시 100만 토큰당 0.98위안(약 190원)으로 수천만 토큰 호출 가능**
- ✅ **임상 진단 가이드라인 및 전문 의학 지식으로 파인튜닝된 Baichuan-M3 Plus 탑재**
- ✅ **OpenAI SDK 프로토콜 100% 호환 (엔드포인트 URL 교체만으로 즉시 연동)**
- 🟢 **완전 선불제 구조: 한도 소진 시 HTTP 402 에러로 안전하게 종료되며 추가 결제 위험 전무**

본 가이드에서는 바이촨 AI의 무료 혜택 상세 규정, 모델별 특징, CORS 정책, 실무 개발 시 주의해야 할 5대 핵심 엔지니어링 팁을 정리해 드립니다.

## 1. 무료 혜택 정책 및 아키텍처: 80위안 가입 바우처

바이촨 AI의 무료 체험은 가입 시 계정에 충전되는 1회성 바우처 형태로 운영됩니다:

| 평가 항목 | 공식 규정 및 실측 결과 | 엔지니어링 분석 및 가이드 |
| :--- | :--- | :--- |
| **무료 유형** | ✅ **`voucher` (신규 가입 바우처)** | 가입 완료 시 계정 잔액으로 80위안 자동 충전 |
| **무료 금액** | **80위안 (CNY, 약 $11.20 USD)** | 모든 모델 호출 시 실시간으로 잔액 차감 |
| **토큰 환산량** | **약 5,000,000 ~ 80,000,000 토큰** | Baichuan4-Air 기준 최대 8,100만 토큰, 혼합 사용 시 약 500만 토큰 |
| **유효 기간** | **3개월 (90일)** | 계정 생성일 기준이며, 기간 만료 시 잔여 바우처 소멸 |
| **속도 제한** | ⚠️ **5 RPM (분당 5회 요청)** | 무료 계정 대상 엄격한 호출 제한 (스트레스 테스트 불가) |
| **신용카드** | ❌ **전혀 불필요** | 결제 수단을 입력하지 않아도 모든 무료 기능 사용 가능 |
| **실명 인증** | ❌ **실명 인증 불필요** | 이메일 인증만으로 API 키 발급 및 호출 지원 |

| **CORS 지원** | ⚠️ **Origin 헤더 정밀 에코** | OPTIONS 요청 시 요청한 Origin을 그대로 반환 (와일드카드 `*` 아님) |
| **결제 안전성** | 🟢 **순수 선불제 (과금 위험 전무)** | 바우처 소진 시 HTTP 402 반환 후 호출 중단, 자동 승인 없음 |

## 2. 주요 모델 라인업 및 추천 활용 분야

바이촨 AI는 비용 효율화, 범용 추론, 헬스케어 특화 등 명확한 타깃 모델을 갖추고 있습니다:

### 1. 극강의 가성비 모델: `Baichuan4-Air`
- **가격 수준**: 1,000토큰당 0.00098위안 = **100만 토큰당 0.98위안(약 190원)**;
- **특징**: 경량 아키텍처로 첫 글자 응답 속도(TTFT)가 극히 빠름;
- **추천 용도**: 대규모 텍스트 전처리, 다국어 번역, 문서 요약, 단순 고객 응대 자동화. 80위안 바우처로 프로토타입 개발을 충분히 완수할 수 있습니다.

### 2. 범용 플래그십: `Baichuan4` / `Baichuan4-Turbo`
- **특징**: 복잡한 문맥 파악, 논리 추론, 역할극(Role-play), 긴 지시문 준수에 최적화된 기저 모델;
- **추천 용도**: 전문 리포트 작성, 다단계 에이전트 워크플로우, 정교한 콘텐츠 기획.

### 3. 의료 전문 플래그십: `Baichuan-M3 Plus`
- **특징**: 방대한 임상 진료 가이드라인, 의학 교과서, 논문 및 전자의무기록(EMR) 기반 파인튜닝 모델;
- **추천 용도**: 헬스케어 상담 챗봇, 임상 진단 보조 PoC, 검진 결과지 해설 보조.

## 3. 빠른 연동 코드 예시 (OpenAI SDK 호환)

바이촨 AI는 표준 OpenAI 엔드포인트 규격을 준수하므로, `baseURL="https://api.baichuan-ai.com/v1"` 설정만으로 즉시 작동합니다.

### Python 연동 예시

```python
from openai import OpenAI

client = OpenAI(
    api_key="your_baichuan_api_key_here",
    base_url="https://api.baichuan-ai.com/v1"
)

response = client.chat.completions.create(
    model="Baichuan4-Air",
    messages=[
        {"role": "system", "content": "당신은 바이촨 AI가 개발한 유능한 인공지능 어시스턴트입니다."},
        {"role": "user", "content": "바이촨 AI의 핵심 강점을 3가지로 요약해 주세요."}
    ],
    temperature=0.3,
    stream=True
)

for chunk in response:
    content = chunk.choices[0].delta.content or ""
    print(content, end="", flush=True)
print()
```

## 4. 개발자가 알아야 할 5대 엔지니어링 주의사항

### 1. 엄격한 5 RPM 속도 제한 (가장 잦은 오류)
무료 계정은 분당 최대 5회(5 RPM)로 요청이 제한됩니다. 반복 루프나 병렬 요청 시 즉시 `HTTP 429 Too Many Requests`가 발생합니다.
> **해결책**: 요청 간 최소 12초 이상의 대기 시간을 두거나 지수 백오프(Exponential Backoff) 재시도 로직을 적용하세요.

### 2. 90일 바우처 유효기간
지급된 80위안 바우처는 가입 후 3개월(90일) 동안 유효합니다. 기간 내 사용하지 못한 잔여 금액은 자동 소멸합니다.
> **해결책**: 가입 후 지체 없이 핵심 비즈니스 PoC 검증 일정을 수립하세요.

### 3. 웹 검색(Search) 플러그인 유료 과금
실시간 웹 검색 기능을 활성화할 경우 호출당 약 0.03위안의 추가 서비스 수수료가 차감됩니다.
> **해결책**: 순수 LLM 추론을 테스트할 때는 검색 플러그인 옵션을 꺼두는 것이 바우처 절약에 유리합니다.

### 4. CORS Origin 정밀 에코 정책
OPTIONS 사전 검사 요청 시 `access-control-allow-origin` 헤더는 와일드카드(`*`)가 아니라 요청한 Origin을 그대로 에코합니다.
> **해결책**: 브라우저 직접 호출 시 정확한 Origin 헤더를 유지하거나 백엔드 프록시 서버를 경유하세요.

### 5. 카드 없는 안전한 선불제 구조
사전에 신용카드를 등록하지 않으므로 잔액이 바닥나면 HTTP 402 오류와 함께 호출이 차단될 뿐, 예상치 못한 요금이 자동 청구될 위험이 완전히 차단되어 있습니다.
