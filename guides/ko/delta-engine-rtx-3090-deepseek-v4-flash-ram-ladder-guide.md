# RTX 3090 단일 장착과 64GB 메모리로 시작하기: Delta Engine v0.93 대형 모델 메모리 계단 검증

일반 소비자용 하드웨어에서 초대형 오픈소스 모델을 구동할 때 첫 번째 난관은 그래픽카드의 연산력 자체가 아니라 메모리 버스 대역폭입니다.

손에 쥔 카드는 24GB VRAM을 갖춘 단일 RTX 3090뿐입니다. 활성 파라미터가 130억 개에 달하는 DeepSeek-V4.1-Flash를 개인 환경에서 부드럽게 구동할 수 있을까요.

오랜 기간 동안 현실적인 답변은 불가능에 가까웠습니다.

가중치를 VRAM에 전부 올리는 것은 불가능합니다. 순수하게 CPU 메모리 오프로드에 의존하면 초당 한두 토큰이라는 답답한 속도에 직면합니다. 비싼 클라우드 대여만이 유일한 방법일까요.

오픈소스 로컬 추론 생태계에서 의미 있는 실측 데이터가 공개되었습니다. 개발자 musicurgy는 최신 출시된 Delta Inference Engine v0.93을 바탕으로 전면적인 벤치마크를 진행했습니다.

이번 테스트의 가치는 모호한 추정을 완전히 배제했다는 점입니다. 동일한 본체를 사용하고 메모리 용량을 단계별로 제한하면서 64GB, 96GB, 128GB, 192GB 구간을 정밀 측정했습니다.

개인용 하드웨어에서 대형 모델을 돌릴 때 어느 구간이 비용 대비 효율의 최적점일까요.

## 벤치마크 테스트베드와 네이티브 Windows 환경

실제 처리량의 기준선을 측정하기 위해 서버용 장비를 일절 배제하고 시판 일반 부품으로만 구성했습니다.

핵심 사양 목록:

- 그래픽카드: 단일 NVIDIA GeForce RTX 3090, 24GB GDDR6X VRAM;
- 프로세서: Intel Core i5-13600K;
- 시스템 메모리: 48GB DDR5-5600 4개 장착, 총 192GB 물리 용량;
- 저장장치: PCIe 4.0 NVMe SSD;
- 운영체제: Windows 11 네이티브 환경, WSL 가상화 미사용.

네이티브 Windows 환경 테스트는 중요한 의미를 가집니다.

대용량 메모리를 장착해 본 분들은 잘 알겠지만, DDR5를 4슬롯 전부 채우면 메모리 컨트롤러 부하로 인해 메인보드가 4400 MT/s 수준으로 자동 강등되는 경우가 흔합니다. 테스트에서는 BIOS 전압과 타이밍을 세밀히 조율해 규격 5600 클럭을 안정 유지하여 대역폭 하락 노이즈를 제거했습니다.

많은 엔지니어가 편의를 위해 WSL2 가상 머신에서 스크립트를 돌리지만, 가상화 계층은 잦은 메모리 매핑과 DMA 전송 과정에서 15% 이상의 성능 저하를 초래합니다.

네이티브 환경에서 직접 하드웨어를 제어하면 불필요한 주소 변환 손실이 없습니다. 측정된 토큰 속도는 물리적 한계를 정직하게 보여줍니다.

## 메모리 구간별 실측: 64GB의 실용화부터 192GB의 최대 속도까지

단일 3090의 24GB VRAM을 고정한 상태에서 시스템 메모리 용량 차이는 생성 속도에 얼마나 영향을 미칠까요.

차이가 얼마나 날까요. 수치로 확인합니다.

탐욕적 샘플링 단일 대화 환경에서 각 메모리 구간과 양자화 규격별 초당 토큰 생성 수를 기록했습니다.

실측 데이터 비교표:

```text
Delta Engine v0.93 디코딩 처리량 비교표:
측정 환경: 단일 RTX 3090 24GB + i5-13600K + DDR5-5600

메모리 구간       기본 양자화   IQ2_XXS    IQ1_S     Q2_K_XL
192GB 풀구성     41.0 t/s     41.0 t/s   31.3 t/s  28.2 t/s
128GB 구간       34.0 t/s     40.6 t/s   26.6 t/s  22.8 t/s
96GB 구간        29.0 t/s     36.5 t/s   22.9 t/s  18.3 t/s
64GB 최소구간    21.0 t/s     30.6 t/s   15.2 t/s  11.7 t/s

참고: 128GB, 96GB, 64GB 데이터는 동일 기기에서 커널 메모리 제한을 걸어 측정.
```

이 데이터로부터 몇 가지 실용적인 기준을 도출할 수 있습니다.

첫째, 64GB 물리 메모리가 실용적인 선택지로 자리 잡았습니다.

이전 엔진 환경에서는 64GB로 이 규모의 모델을 돌리면 즉시 튕기거나 심각하게 지연되었습니다. Delta Engine v0.93을 통해 64GB 환경이 비로소 작동 가능한 상태가 되었습니다.

기본 양자화에서도 21 t/s를 기록하며, 저비트 폭에 최적화된 Unsloth IQ2_XXS를 적용하면 30.6 t/s까지 올라갑니다. 초당 30단어 이상은 사람의 독서 속도를 웃돌아 일상 코딩 보조 도구로 충분히 쓸 수 있습니다.

둘째, 128GB 구간의 뛰어난 가격 대비 성능입니다.

IQ2_XXS 설정에서 128GB 구성은 40.6 t/s를 보여 192GB 풀구성의 41.0 t/s와 거의 차이가 없습니다. 이것이 뜻하는 바는 무엇일까요.

경량화 양자화 모델 운용이 주 목적이라면 무리해서 192GB까지 슬롯을 채울 필요가 없다는 뜻입니다. 절약한 예산은 고속 NVMe SSD에 투자하는 편이 훨씬 합리적입니다.

긴 문서 입력 처리 성능도 안정적입니다. 64K 컨텍스트 Prefill 구간에서:

- 192GB 구성은 87초 소요, 초당 740 토큰으로 환산;
- 128GB 구성은 107초 소요, 초당 600 토큰으로 환산;
- 짧은 질문 입력 시 약 2초 만에 첫 응답이 출력됩니다.

## 성능 검증: 99가지 난제 벤치마크와 양자화의 대가

커뮤니티에서는 4비트 미만의 극단적 양자화가 지능을 파괴하여 장난감에 불과해지는 것 아니냐는 우려가 늘 제기됩니다.

낮은 비트로 깎으면 모델이 무용지물이 될까요. 테스트 결과가 답을 제시합니다.

지능 유지도를 평가하기 위해 99가지 고난도 문제로 구성된 표준 테스트 세트를 활용해 추론 토큰 43K, 탐욕 모드로 비교했습니다.

평가 점수 비교표:

```text
고난도 99문제 벤치마크 점수 비교:
만점은 99점이며 점수가 높을수록 문제 해결력이 우수함

구성 모델                    총점   지식(40)  수학(14)  추론(30)  기본코드(10)  난제코드(5)
공식 클라우드 API 전정밀도   59점   13점      10점      25점      10점          0점
UD-IQ2_XXS 로컬 빌드        52점   12점      10점      25점      10점          0점
초기 DS4 Q2 구버전           47점   9점       10점      23점      8점           0점
```

이 항목별 수치는 직관과 다른 기술적 현실을 보여줍니다.

수학, 논리 추론, 기본 코드 생성 3개 핵심 영역에서 UD-IQ2_XXS는 전정밀도 API와 완벽히 동일한 만점을 획득했습니다. 수학 10점 만점, 추론 25점 만점, 코드 10점 만점 동률입니다.

극단적 양자화로 인해 논리 지능이 붕괴될 것이라는 염려는 엄밀한 수학 및 논리 영역에서 발생하지 않았습니다.

실제 감점은 광범위한 일반 상식 분야에 집중되었습니다. 40개 상식 문항 중 공식 API는 13점, IQ2_XXS는 12점을 받았습니다.

상징적인 대목은 가장 어려운 코딩 5문항으로, 클라우드 공식 버전과 로컬 양자화 버전 모두 0점을 기록했습니다.

스크립트 작성, 테스트 생성, 모듈 리팩터링처럼 논리 구조가 중요한 실무 작업에서 IQ2_XXS는 핵심 추론 뼈대를 충분히 보존합니다.

다만 지엽적 역사나 특수 사실 암기에 의존하는 작업에서는 지식 누락이 나타납니다. 정확한 지식 인출이 필수적이라면 속도가 28 t/s로 떨어지더라도 UD-IQ3_XXS를 선택해야 합니다.

## 현실적 한계와 두 가지 하드웨어 접근법

이 테스트 결과를 바탕으로 개발자가 3090과 대용량 메모리를 즉시 구매해야 할까요.

구매 전 반드시 짚어야 할 하드웨어 기준선이 있습니다.

VRAM 용량은 타협할 수 없습니다.

DeepSeek-V4.1-Flash는 활성 파라미터가 130억 개이므로 단일 GPU 구동 시 VRAM 마지노선은 16GB에서 24GB 사이입니다. RTX 3090의 24GB는 시스템 파단을 막기 위한 필수 조건입니다.

VRAM이 부족하면 어떻게 해야 할까요. 8GB나 12GB 카드를 가진 사용자는 이 구성을 무리하게 시도해서는 안 됩니다. 활성 파라미터가 60억 개 수준인 Qwen3.8-Flash-Next로 눈을 돌리는 것이 실용적입니다.

비용과 전력 구조도 비교해야 합니다.

동시에 흥미로운 대조 사례가 나타났습니다. 2018년식 Tesla V100 8장을 랙에 장착해 약 4000달러를 투입하고 초당 200토큰을 뽑아낸 사례입니다. 하지만 디코딩 시 1.1kW의 전력을 상시 소비해 월 전기 요금만 약 80달러에 달합니다.

3090 한 장과 64GB에서 128GB 메모리 조합은 현실적인 개인용 접근법입니다. 대기 전력은 100W 미만이고 최대 가동 시에도 200W 초반에 머뭅니다. 속도는 30에서 40 t/s 수준이지만 소음과 전기세 부담이 없습니다.

기술 도입의 본질은 무조건적인 랙 증설이 아니라 한정된 예산 안에서 처리량과 비용의 최적 균형점을 찾는 데 있습니다.

64GB부터 가동되는 이 실용적인 계단 구조를 바탕으로 기존 장비의 메모리를 증설할지, 중고 3090을 들여 개인용 계산 노드를 구축할지 판단해 보시기 바랍니다.
