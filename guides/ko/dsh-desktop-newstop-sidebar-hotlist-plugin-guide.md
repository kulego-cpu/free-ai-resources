# Agent 추론을 모니터링하며 기술 트렌드 확인하기: DSH Desktop 사이드바 플러그인 DS-NewsTop 아키텍처 및 실측 가이드

로컬 환경에서 긴 호흡의 작업을 실행할 때.
예를 들어 Agent에게 대규모 모듈 리팩토링을 맡기는 상황.
모델 추론에는 보통 2분에서 3분 정도의 대기 시간이 발생합니다.
웹 브라우저를 열어 피드를 확인하다 보면 집중력이 흐트러지기 쉽습니다.
다시 에디터로 돌아왔을 때 검토하려던 코드 맥락을 놓치곤 합니다.
AI 개발 도구 내부에 가벼운 사이드바가 상주한다면 어떨까요.
터미널 로그를 주시하면서 커뮤니티의 기술 이슈를 가볍게 훑어봅니다.
확인이 끝나면 바로 접어둡니다.
메인 코드 작업 영역을 침범하지 않습니다.

오픈소스 플러그인 DS-NewsTop이 이 요구에 부합합니다.
DSH Desktop 환경에 맞춤 설계되었으며 Cordis 모듈식 구조를 통해 다양한 플랫폼의 트렌드를 사이드바에 통합합니다.

## 1. 아키텍처 분석: 동일 출처 프록시와 백그라운드 폴링 배제

DSH에 이 플러그인을 설치하기 전, 내부 타이머 루프가 존재하는지부터 확인했습니다.

경험에서 비롯된 확인이었습니다.
작년에 90초 주기로 수십 개 엔드포인트를 동시 호출하는 유사 확장을 사용한 적이 있습니다.
당시 7B 모델 추론을 구동하고 있었는데 냉각 팬이 급격히 회전하기 시작했습니다.
그 이후 실시간 피드를 표방하는 확장 프로그램을 보면 소스 코드에서 setInterval 함수부터 확인하는 습관이 생겼습니다.

DS-NewsTop에는 백그라운드 폴링 타이머가 없습니다.
패널을 열었을 때만 요청을 보내고 닫혀 있는 동안에는 통신을 완전히 중단합니다.
이 설계가 해당 도구를 사이드바에 고정할지 결정하는 핵심 기준이 되었습니다.

요청 경로도 간결하게 통일되었습니다. 프론트엔드는 호스트의 로컬 엔드포인트만 호출합니다.
`/dsh-hot-list/items?id=sourceID`
프론트엔드는 이 로컬 포트에서만 데이터를 받아옵니다.
호스트 계층이 사전에 고정된 업스트림 목록을 참조하여 통신을 수행합니다.
업스트림 주소는 호스트 코드 내부에 상수로 고정되어 프론트엔드에서 임의의 파라미터를 넘겨도 반영되지 않습니다.
처음에는 대수롭지 않게 여겼으나 SSRF 공격 관점을 떠올리면 필수적인 통제입니다.
만약 임의의 URL 호출을 허용했다면 내부망 스캔에 악용되는 오픈 프록시로 전락할 위험이 있습니다.

60초 인메모리 캐시도 유용합니다.
사이드바를 자주 여닫아도 외부 네트워크에 불필요한 패킷을 보내지 않고 즉시 화면을 띄워줍니다.

데이터 수집 경로는 두 갈래로 나뉩니다.
GitHub, Hacker News, V2EX, Zhihu 등 18개 주요 사이트는 오픈소스 NewsNow 서비스를 경유합니다.
Appinn 커뮤니티 발견 채널의 Markdown 문서는 전용 파서로 처리하여 공지 규칙을 거르고 상위 공유 항목을 추출합니다.

업스트림 노드가 502 오류를 반환하더라도 직전에 가져온 목록을 화면에 유지하고 재시도 버튼을 띄웁니다.
NewsNow 서비스가 일시적으로 흔들렸을 때도 이전 목록이 남아 있어 작업 흐름이 끊기지 않았습니다.

## 2. 호환성 경계 조건과 실측 자원 소모량

3시간 연속 구동하며 메모리 누수 여부와 CPU 점유율을 관찰했습니다.
macOS 활성 상태 보기 도구로 측정한 수치이므로 전문 프로파일러 수준의 엄밀한 계측은 아니며 참고용 지표입니다.

### 테스트 벤치마크 환경
- 호스트 환경: DSH Desktop 2.0.18, 코어 호환 버전 0.2.1-rc.2 및 0.2.1-rc.3
- 하드웨어 사양: M2 Max 칩 탑재 MacBook Pro, 32GB 통합 메모리
- 플러그인 버전: dsh-hot-list 1.3.2 릴리스

### 실기 구동 성능 비교 장부

메모리의 경우 콜드 스타트 후 40MB에서 50MB 범위 증가로 안정화되었습니다.
3시간 동안 뚜렷한 메모리 누수 현상은 관찰되지 않았습니다.
비교를 위해 Chrome 128 환경에서 뉴스 탭 7개를 열었을 때 활성 상태 보기에 약 1.1GB에서 1.3GB의 메모리 점유가 나타났습니다.
다만 탭 개수나 브라우저 절전 기능 활성화 여부에 따라 편차가 크므로 개략적인 규모 비교로 보아야 합니다.

CPU 점유율의 경우 샘플링 구간 내내 프로세스 수치가 0.0을 가리켰습니다.
0.0 수치가 절대적인 0을 뜻하는 것은 아니며 모니터링 도구의 표시 해상도보다 낮은 부하를 의미합니다.
확인할 수 있었던 점은 가시적인 부하 급증이 없었고 오후 내내 쿨링 팬 소음이 발생하지 않았다는 사실입니다.

| :--- | :--- | :--- | :--- |
| 상주 메모리 점유 증가분 | 약 1.1GB에서 1.3GB 소모 | 호스트 프로세스 메모리 약 45MB 증가 | 무거운 브라우저 엔진과 추적 스크립트 배제 |
| 유휴 상태 CPU 점유율 | 페이지 스크립트로 간헐적 1% | 활성 상태 보기 수치 0.0 유지 | 측정 해상도 미만, 급격한 부하 없음 |
| 외부 네트워크 요청 시점 | 2분 주기 지속적인 백그라운드 요청 | 패널 호출 또는 갱신 버튼 클릭 시만 발생 | 추론 네트워크 대역폭 보호 |
| UI 테마 시각적 동기화 | 외부 확장 프로그램 강제 반전 필요 | DSH 호스트 배경 및 테두리 변수 상속 | 라이트, 다크, 호스트 자동 연동 지원 |
| 에코시스템 지원 범위 | 일반 웹 브라우저 환경 전반 | DSH Desktop의 Cordis 체계에 종속 | 순정 VS Code나 Cursor에 직접 설치 불가 |

기술적 한계를 명확히 짚어야 합니다.
이 도구는 DSH Desktop의 Cordis 플러그인 체계에 맞춰 제작되었습니다.
일반적인 VS Code 마켓플레이스 확장이 아니므로 순정 VS Code에 직접 로드할 수 없습니다.
비 DSH 환경에서 유사한 환경을 구축하려면 카드 UI와 NewsNow API를 참조하여 별도 이식해야 합니다.
호환되지 않는 환경에 무리하게 설치하지 마십시오.

## 3. 실전 배포: 사이드바 연동 3단계 절차

DSH Desktop 2.0.18 환경에 플러그인을 설치하는 과정은 다음과 같습니다.

### 1. 패키지 의존성 설치
DSH Desktop을 실행합니다.
상단 메뉴에서 내장 터미널을 호출한 후 기본 데스크톱 Profile 디렉터리로 이동합니다.

```bash
cd ~/.dsh/profiles/desktop
pnpm add dsh-hot-list@1.3.2
```

GitHub Releases에서 tgz 압축본을 내려받아 절대 경로로 설치할 수도 있습니다.

### 2. 프로필 설정 파일에 번들 등록
해당 디렉터리의 package.json 파일을 엽니다.
dsh.profile.bundles 배열 항목에 dsh-hot-list를 추가합니다. 기존 공식 패키지는 그대로 유지합니다.

```json
{
  "dsh": {
    "profile": {
      "bundles": [
        "@deepseek-ai/dsh-base",
        "@deepseek-ai/dsh-web-app",
        "dsh-hot-list"
      ]
    }
  }
}
```

JSON 문법을 꼼꼼히 확인합니다.
중괄호가 누락되거나 끝부분에 쉼표가 잘못 붙으면 프로필 자체가 정상적으로 로드되지 않습니다.

### 3. 재시작 및 동작 검증
DSH Desktop을 완전히 종료한 후 다시 실행합니다.
클라이언트 좌측 활동 바에 핫리스트 아이콘이 나타납니다.
아이콘을 클릭하여 사이드바를 호출합니다.
우측 상단 톱니바퀴 메뉴에서 19개 정보 소스를 필요에 따라 선택할 수 있습니다. 기본값은 14개입니다.
설정값은 DSH 로컬 스토리지에 자동 저장됩니다.

## 4. 최종 인수 점검 목록

다음 네 가지 항목을 점검하여 설정을 마칩니다.
- 상주 메모리 확인: 호스트 메모리 증가량이 50MB 안팎에서 유지되는지 확인합니다.
- 오프라인 복원력 검증: 네트워크가 끊긴 상태에서 카드를 클릭했을 때 흰 화면 오류 대신 직전 캐시 목록과 재시도 안내가 유지되는지 확인합니다.
- 테마 연동 확인: DSH를 다크 모드로 전환했을 때 테두리와 배경색이 즉시 변경되는지 확인합니다.
- 유휴 네트워크 점검: 패킷 캡처를 통해 사이드바를 닫았을 때 외부 트래픽이 0바이트로 유지되는지 확인합니다.
