## 1. 왜 기존 클라우드 회의록 도구는 기업 정보 유출의 온상인가?

업무 생산성을 위해 기업 기밀을 도박판에 올려놓아야 할까요?
원인은 클라우드 도구들의 안일한 아키텍처에 있습니다.

시중의 대다수 상용 회의록 서비스는 단순한 원격 중계기에 불과합니다.
첫째, 브라우저 확장 프로그램으로 마이크와 스피커 음성을 녹음합니다；
둘째, 원본 음성 스트림을 클라우드 데이터센터로 전송합니다；
셋째, 원격 서버에서 모델을 돌린 뒤 요약된 텍스트를 화면으로 돌려보냅니다.

겉보기에는 편리합니다.
하지만 실상은 극도로 위험합니다!
내부 대화, 격렬한 논쟁, 말로 주고받은 테스트 비밀번호까지 전부 타인의 서버 하드디스크에 고스란히 저장됩니다.
서버 설정 오류나 해킹, 내부 직원의 일탈이 발생하면 기업 기밀은 그 즉시 공공재가 됩니다.
이것은 비서가 아닙니다.
언제 터질지 모르는 시한폭탄입니다!

Natively 3.0의 접근법은 매우 명확합니다.
외부 인터넷 연결 통로를 완전히 끊어버려라!
음성 인식, 언어 모델 추론, 기록 보관의 전 과정을 PC 로컬 환경 안에 가두어 둡니다.

## 2. 구조 분석：완전 오프라인 회의록을 지탱하는 3가지 기둥

인터넷이 차단된 노트북에서 어떻게 긴 시간의 회의를 처리할 수 있을까요?
내부 파이프라인은 세 가지 저수준 모듈로 구성됩니다.

### 1. Rust 기반 제로카피 오디오 분리 파이프라인
웹 브라우저의 WebAudio 인터페이스는 레이턴시와 음질 왜곡을 유발합니다.
Natively는 밑바닥부터 Rust로 네이티브 오디오 수집 엔진을 구현했습니다.
운영체제 저수준 API를 통해 상대방의 스피커 음성을 직접 낚아채고；
동시에 사용자의 마이크 입력을 별도 트랙으로 독립 수집합니다.
양방향 채널이 물리적으로 분리됩니다.
스피커 소리가 마이크로 재입력되어 잡음으로 인식되는 오류를 원천 차단합니다.

### 2. 기기 내부 완결형 Whisper 및 Parakeet 음성 인식
파이프라인으로 들어온 오디오 조각은 최적화된 ONNX 엔진으로 즉시 전달됩니다.
애플 실리콘 Mac에서는 Metal 및 CoreML 하드웨어 가속을 활용하고；
Windows 환경에서는 DirectML 인터페이스를 사용합니다.
응답 지연 시간은 0.5초 미만으로 단축됩니다!
음성 인식 요금을 결제할 필요가 없습니다.
음성 데이터가 유출될 걱정도 전혀 없습니다.

### 3. Ollama 연동 및 로컬 MCP 서버 구동
텍스트로 변환된 실시간 문자열은 로컬에서 실행 중인 Ollama 데몬으로 직결됩니다.
사양에 따라 Qwen2.5 7B 나 Llama3.2 3B 같은 오픈 가중치를 자유롭게 선택할 수 있습니다.
최신 3.0 버전에서는 로컬 루프백 네트워크에 가벼운 MCP 서버를 띄우는 기능까지 추가되었습니다!
터미널에서 실행 중인 다른 로컬 에이전트 도구가 이 인터페이스로 직접 질의를 던질 수 있습니다.
지난주 회의에서 합의된 데이터베이스 규격이 무엇이었는지 즉각 조회할 수 있습니다.

## 3. 실기 벤치마크：가감 없는 하드웨어 부하 데이터

이 로컬 파이프라인이 실제 회의 환경을 버텨낼 수 있을까요?
실제 작업용 MacBook Pro 에서 강도 높은 측정을 진행했습니다.

### 테스트 하드웨어 사양
- 측정 장비：MacBook Pro M2 Max 칩셋, 32GB 통합 메모리
- 로컬 LLM：Ollama 환경에서 구동한 Qwen2.5 7B Instruct
- 음성 인식 모델：Whisper large-v3-turbo CoreML 양자화 버전
- 대조군：일반적인 상용 클라우드 회의록 SaaS 클라이언트

### 45분간의 기술 회의 실측 비교표

5회의 실전 기술 회의 데이터를 수집하여 중앙값을 도출했습니다.

| 평가 항목 및 측정 시나리오 | 기존 상용 클라우드 서비스 | Natively 3.0 완전 로컬 구동 | 측정 결과 및 시스템 상태 |
| :--- | :--- | :--- | :--- |
| 음성 데이터의 외부 전송량 | 시간당 수백 메가바이트 전송 | 완전한 제로 바이트 외부 전송 없음 | 최고 수준의 기밀 유지 요건 충족 |
| 음성 인식 구간 반응 지연 시간 | 800밀리초에서 1.5초 변동 | 450밀리초에서 600밀리초 안정 | Rust 기반 네이티브 파이프라인 우위 |
| 회의 요약 및 할 일 추출 시간 | 클라우드 클러스터 기준 약 4초 | 로컬 7B 모델 기준 약 8초 소요 | 로컬 연산 능력 한계로 속도는 열세 |
| 시스템 메모리 최대 점유율 | 앱 단독 약 450MB 수준 | 호스트 전체에서 22GB 점유 | 기기 내부 AI 동시 실행의 물리적 대가 |
| 발열 및 냉각팬 소음 상태 | 본체 미온 상태로 팬 미작동 | 본체 발열 발생 및 팬 회전 | 지속적인 고부하 행렬 연산의 발열 |

비교표의 하단 항목들을 주의 깊게 살펴보십시오!
공짜 소프트웨어라고 해서 하드웨어 자원까지 공짜는 아닙니다.
화상 회의 자체가 카메라와 화면 공유로 상당한 자원을 소모합니다.
거기에 Whisper 가 쉬지 않고 오디오를 삼키고；
백그라운드에서 Ollama 가 텍스트를 추론합니다.
통합 메모리 점유율이 순식간에 22GB까지 치솟습니다!
팬이 돌기 시작합니다.
온도는 85도에 육박합니다.
만약 여러분의 노트북 메모리가 8GB 나 16GB라면 지금 당장 포기하십시오.
저사양 장비에서 무리하게 이 파이프라인을 돌렸다가는 화상 회의 앱 자체가 멈춰버리는 대참사를 겪게 될 것입니다!

## 4. 트러블슈팅과 커뮤니티의 날카로운 쟁점

이틀간 깊이 있게 사용하면서 겪었던 두 가지 함정과 커뮤니티의 핵심 논쟁을 정리했습니다.

### 1. 마이크 독점 모드로 인한 무음 현상
설치 직후 상대방의 목소리는 완벽하게 텍스트로 바뀌는데, 내가 한 말은 기록에서 완전히 사라졌습니다.
원인을 분석해 보니 화상 회의 프로그램이 운영체제 마이크 채널을 독점 잠금하고 있었습니다.
해결책은 간단합니다.
설정 창을 열고 오디오 캡처 방식을 마이크 직결 모드에서 시스템 믹서 혼합 모드로 변경하면 됩니다.
말끔히 해결되었습니다.

### 2. 문맥 과부하로 인한 추론 지연
Ollama 의 컨텍스트 크기를 지나치게 크게 잡으면 회의가 30분을 넘어갈 때 7B 모델의 생성 속도가 뚝 떨어집니다.
발언 속도가 빨라지면 메모리 큐에 오디오 조각이 밀리기 시작합니다.
슬라이딩 윈도우 크기를 8192 토큰 이내로 고정하십시오.
주기적으로 끊어서 요약하도록 설정하는 것이 안정성의 핵심입니다.

### 3. 커뮤니티 논쟁：로컬 MCP 서버의 접근 권한 허점
Reddit 의 엔지니어 kantorcodes1 이 날카로운 질문을 던졌습니다.
Natively 3.0 의 로컬 MCP 서버에 안전한 읽기 전용 격리 기능이 있는가?
현재 구현은 다소 거칠게 열려 있습니다.
로컬 포트 번호만 알면 다른 도구가 MCP 프로토콜을 통해 접근할 수 있습니다.
검증되지 않은 외부 에이전트 스크립트를 PC에서 실행할 경우, 회의록을 몰래 훔쳐보는 것은 물론이고 과거 기록을 위조하거나 삭제할 위험도 배제할 수 없습니다!
공식 업데이트로 엄격한 토큰 인증과 읽기 전용 스위치가 도입되기 전까지는 이 포트를 외부 자율 에이전트에 함부로 연결하지 마십시오.

### 4. 스폰서 광고에 대한 주의점
GitHub 저장소 상단에는 상용 화면 녹화 API 의 홍보 배너가 걸려 있습니다.
개인 용도로는 소스가 공개된 무료 툴이지만, 제작자가 향후 클라우드 유료 플랜을 도입할 가능성을 시사합니다.
사용할 때는 철저히 로컬 설정을 고수하십시오.
오직 로컬 Ollama 만 연결하고 클라우드 유료 부가 기능을 피하는 것이 현명합니다.

## 5. 실전 가이드：로컬 환경 구축 3단계

데이터 보안을 최우선으로 생각하는 엔지니어라면 다음 세 단계로 즉시 구성할 수 있습니다.

### 1. 로컬 Ollama 구동
터미널에서 Ollama 를 띄우고 신뢰할 수 있는 모델을 내려받습니다.

```bash
ollama run qwen2.5:7b
```

### 2. 클라이언트 설치
Mac 에서는 Homebrew 로 간편하게 설치합니다.

```bash
brew install --cask Natively-AI-assistant/tap/natively
```

### 3. 완전 오프라인 설정
앱 내부 설정 창을 엽니다.
- 모델 제공자에 Ollama 를 지정하고 로컬 포트 11434 를 입력합니다.
- 음성 인식 엔진으로 로컬 Whisper 를 선택합니다.
- 클라우드 동기화와 외부 공유 스위치를 모두 끄고 로컬 전용 표시를 확인합니다.

Wi-Fi 를 끄고 비행기 탑승 모드에서 직접 음성을 녹음해 보십시오.
인터넷 연결 없이 화면 위에 실시간으로 출력되는 자막과 구조화된 할 일 목록.
데이터를 완벽하게 내 손안에 쥐고 있다는 안도감은 그 어떤 클라우드 구독 서비스도 줄 수 없는 가치입니다!
