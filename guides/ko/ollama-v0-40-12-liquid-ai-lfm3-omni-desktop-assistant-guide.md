# 2B 온디바이스 Omni 시대 개막: Ollama v0.40.12의 Liquid AI LFM3 전 패밀리 내장 실전 가이드

로컬 거대언어모델 런타임의 표준인 **Ollama**가 최신 프로덕션 정식 버전인 **v0.40.12**를 전격 공개했습니다!

이번 업데이트의 백미는 단연 전 MIT CSAIL 연구진이 창업한 Liquid AI의 최신 파운데이션 모델 제품군인 **LFM3(Liquid Foundation Models 3) 전 패밀리를 공식 네이티브로 내장**했다는 점입니다.

이는 1.7B~2B 수준의 초경량 크기에서 **256K에 달하는 방대한 초장문 컨텍스트 윈도우**를 갖추고, 텍스트·시각·음성을 단일 신경망으로 처리하는 풀 모달리티(Omni) 모델을 터미널 명령어 한 줄로 즉시 구동할 수 있게 되었음을 의미합니다.

오늘 FreeAI Dog에서는 LFM3 패밀리의 스펙 구성, 로컬 멀티모달 데스크톱 비서 구축법, 그리고 주의해야 할 하드웨어 지원 범위와 상업적 라이선스 경계를 상세히 안내해 드립니다.

---

## 1. LFM3 아키텍처 분석: 왜 Tri-hybrid 구조가 강력한가?

전통적인 트랜스포머 기반의 소형 모델은 컨텍스트 길이가 8K나 16K를 넘어서면 어텐션 연산 특성상 메모리와 연산 지연이 기하급수적으로 폭증하는 한계를 가졌습니다. 반면 순수 RNN이나 SSM 계열은 정밀한 팩트 검색 성능에서 아쉬움을 보이는 경우가 많았습니다.

Liquid AI의 **Tri-hybrid(3원 하이브리드 컴퓨팅 아키텍처)**는 합성곱(로컬 특징 초고속 추출), 상태 공간 모델(SSM, 무한 스트리밍 처리), 선형 어텐션 연산자를 절묘하게 결합하여 **1.7B ~ 2B**의 가벼운 크기에서 혁신적인 라인업을 완성했습니다:

| 모델 ID | 파라미터 | 핵심 역할 | 주요 스펙 및 강점 |
| :--- | :--- | :--- | :--- |
| **`lfm3`** | 1.7B | 로컬 초고속 Agent 기저 모델 | **256K 초장문 컨텍스트**, 도구 호출(Tool Calling) 및 구조화 JSON 출력 완벽 지원 |
| **`lfm3-vl`** | 약 2B | 경량 비전 멀티모달 | 고해상도 이미지 이해, 차트 및 문서 표 분석, 화면 인식 |
| **`lfm3-audio`** | 약 2B | 전이중 음성 인식 및 합성 엔진 | 초정밀 STT + 번역 + 18개 언어 네이티브 TTS(주요 오픈소스 최초 폴란드어 음성 지원) |
| **`lfm3-omni`** | 약 2B | **텍스트 + 이미지 + 오디오 올인원** | 여러 모델을 거치지 않는 엔드투엔드 단일 멀티모달 추론으로 지연 시간 극소화 |
| **`d1:2b`** | 2B | 초고속 의도 분류 및 라우팅 | 밀리초 단위의 참/거짓 및 다중 선택 판단에 특화 |

## 2. 10초 퀵스타트: 명령어 한 줄로 LFM3 실행하기

Ollama v0.40.12로 업데이트한 후, 단일 명령어로 즉시 모델을 불러올 수 있습니다:

### 1. 256K 긴 문맥 로컬 Agent 실행
```bash
# 1.7B 256K 텍스트 모델 실행
ollama run lfm3
```
통합 메모리 점유율은 불과 **약 1.2GB**. 대형 코드베이스나 책 한 권 분량의 기술 문서를 한 번에 입력해도 최신 노트북에서 **초당 80개 이상의 토큰(80+ tokens/s)**을 가뿐히 생성합니다.

### 2. 밀리초 단위 의도 라우팅 모델 `d1:2b`
복잡한 멀티 에이전트 환경에서 단순한 의도 분류 작업에 70B 대형 모델을 사용하는 것은 극심한 낭비입니다:
```bash
# 네이티브 --ask 플래그를 통한 초고속 이진 판단
ollama run d1:2b "I was charged twice for order 4417." \
  --ask "Is this a billing issue?"
```
수십 밀리초 만에 명확한 불리언(Boolean) 값을 반환하므로 로컬 파이프라인의 관문으로 최적입니다.

### 3. 일체형 멀티모달 Omni 데스크톱 어시스턴트
`ollama run lfm3-omni`를 통해 스크린샷과 마이크 음성 스트림을 단일 모델에 직접 전달할 수 있습니다. 기존의 "Whisper 음성인식 → LLM 추론 → TTS 음성합성"의 3단계 파이프라인 지연이 사라져, 컴퓨터 화면을 실시간으로 보며 대화하는 개인용 비서를 구현할 수 있습니다.

## 3. Ollama v0.40.12 주요 개선 사항

LFM3 외에도 이번 릴리스에는 다음과 같은 실전 개선이 포함되었습니다:
1. **Apple Silicon 프롬프트 가속**: Gemma 4, Flint, Laguna 모델의 M 시리즈 칩셋 전처리 속도 대폭 향상;
2. **DFlash2 투기적 디코딩(Speculative Decoding)**: MLX 파이프라인 결합으로 추론 처리량 30%~50% 개선;
3. **OpenCode v2 공식 지원**: `ollama launch` 명령어의 개발 협업 생태계 확장;
4. **Kimi CLI 버그 픽스**: 도구 전용 어시스턴트 턴 상태 전환 오류 수정.

또한 llama.cpp 핵심 개발자 `tdakhran`과의 공조로 **출시 당일 제로데이(Zero-Day) 지원**이 완료되었습니다.

## 4. 하드웨어 지원 제약 및 라이선스 안내

FreeAI Dog는 기술적 제약 사항을 투명하게 안내합니다:

1. **⚠️ 현재 하드웨어 플랫폼 제약**:
   * v0.40.12 기준, **`lfm3` 및 `d1:2b` 최적화 백엔드는 Apple Silicon(Mac M 시리즈) 하드웨어에 우선 지원**됩니다;
   * Linux(CUDA/ROCm) 및 Windows 지원은 현재 마무리 작업 중이며 후속 패치 버전에서 빠르게 지원될 예정입니다.
2. **⚠️ 상업적 라이선스 규정**:
   * Liquid AI는 유연한 계층형 라이선스를 채택했습니다: **개인 연구자, 학술 프로젝트, 비영리 단체, 연간 총매출 1,000만 달러(약 140억 원) 미만의 중소 규모 기업은 완전 무료**;
   * 연 매출 1,000만 달러를 초과하는 기업이 상용 제품의 핵심으로 탑재할 경우 라이선스 계약이 필요합니다;
   * 완전한 무제한 상업적 자유를 원하신다면 Apache 2.0 라이선스의 Gemma 4나 Qwen 제품군을 권장합니다.
