# SenseNova: 모바일 게임처럼 '주기적으로 충전되는' 독특한 무료 체계

중국 AI 대표 기업 SenseTime(상탕테크)의 주력 거대 모델 **SenseNova**는 현재 **Token Plan 무료 퍼블릭 베타**를 운영 중입니다. 타사 모델과 확연히 구분되는 가장 큰 특징은 **듀얼 풀 스태미나 자동 회복 시스템**입니다.

---

## 1. '스태미나 자동 충전'이란?

대다수 AI 제공업체는 1회성 무료 쿠폰(소진되면 결제 필수)을 제공합니다.
하지만 SenseNova는 **일정 주기마다 가득 차는 충전형 포인트 풀**을 운영합니다:

1. **범용 포인트 풀**: 5시간마다 **60,000 포인트** 자동 충전 (주간 상한 60만 pt);
2. **Flash-Lite 전용 풀**: 5시간마다 추가 **60,000 포인트** 보너스 지급;
3. **총 충전 속도**: **5시간마다 12만 포인트 회복, 매주 약 120만 포인트 완전 무료!**

초대형 동시 호출을 계속 돌리지 않는 이상, 몇 시간만 지나면 잔여 쿼터가 가득 차므로 사실상 지속적인 영구 무료 이용이 가능합니다.

---

## 2. 핵심 강점: 네이티브 멀티모달 시각 인식

컴퓨터 비전 기술력에 강점을 가진 SenseNova 6.8 아키텍처는:
- 복잡한 도표 및 차트 분석
- 스캔 PDF 문서의 데이터 추출
- 네이티브 비전 멀티모달 추론

등에 특화되어 있으며, 단순 텍스트 변환 대비 토큰 소모량을 약 60% 절감할 수 있습니다.

---

## 3. 3단계 가입 절차

1. SenseNova 공식 플랫폼 접속:
   👉 [https://platform.sensenova.cn](https://platform.sensenova.cn)
2. 가입 및 로그인 완료 시 계정에 **0원/월 베타 플랜** 자동 활성화;
3. "API 키" 메뉴에서 새 API Key 발급;
4. 엔드포인트는 표준 OpenAI와 완벽 호환(`https://token.sensenova.cn/v1`)됩니다.
