# SiliconFlow: 오픈소스 거대 모델을 가장 합리적으로 호출하는 허브

SiliconFlow(SiliconCloud)는 오픈소스 LLM 추론 가속에 특화된 대표적인 API 플랫폼입니다. 고가용 BGP 네트워크를 갖추어 평균 응답 지연 시간이 **180ms ~ 200ms**에 불과하며, 개인 개발자 및 연구원을 위한 최고의 AI 인프라를 제공합니다.

무료 바우처를 어떻게 수령하는지, 혹은 호출 시 발생하는 `403 Forbidden`이나 `504 Gateway Timeout` 오류로 곤란을 겪는 분들을 위해, Hermes의 최신 벤치마크 데이터를 바탕으로 **16위안 바우처(180일 유효기간)** 획득법과 **공식 영구 0원 20개 모델 풀**의 실전 활용법을 총정리해 드립니다.

---

## 1. 혜택 내용 및 바우처 실질 가치

### 1. 16위안(CNY) 전 플랫폼 공용 바우처 (180일 유효기간)
- **이벤트 기간**: **2026년 12월 31일**까지 공식 진행.
- **넉넉한 유효기간**: 수령일로부터 **180일(6개월)** 동안 자유롭게 사용 가능.
- **강력한 실질 가치**:
  - 풀스펙 671B `deepseek-ai/DeepSeek-V3` 정가는 100만 토큰당 약 2위안(심야 할인 시 1위안).
  - **16위안 바우처로 약 1,600만 ~ 2,000만 토큰**을 이용할 수 있습니다.
  - 바우처 소진 시 호출이 중단될 뿐, **신용카드나 계좌에서 자동 결제되는 일은 절대 없습니다**.

### 2. 초대 제한 없는 앰배서더 프로그램
- 콘솔 "활동 센터"에서 친구를 초대하면 **양측 모두에게 16위안 바우처**가 지급됩니다.
- 초대 인원 제한이 없어 영구적인 0비용 RAG 클러스터 운영이 가능합니다.

## 3. 핵심 오류 해결 및 활용 팁

### 주의점 1: 미인증 시 유료 모델 호출 시 403 Forbidden 에러
- 미인증 계정은 남용 방지를 위해 무료 풀의 극히 일부 모델만 허용됩니다.
- 본인 인증을 완료하면 16위안 바우처가 입금되면서 풀스펙 모델 및 60 RPM 동시성이 즉시 활성화됩니다.

### 주의점 2: 장문 생성 시 504 Gateway Timeout 해결법
- 긴 생각 과정이나 장문 작성 시, 일반(Non-streaming) 연결은 약 60초 후 게이트웨이 타임아웃(504)으로 끊어질 수 있습니다.
- **클라이언트 설정에서 `stream: true`를 활성화**하여 실시간 스트리밍으로 수신하면 504 오류를 완전히 방지할 수 있습니다.

### 주의점 3: Anthropic Messages 프로토콜 네이티브 지원
SiliconFlow는 OpenAI 표준뿐만 아니라 **Anthropic Messages 규격도 네이티브 지원**합니다!
- **Claude Code, Cursor, Cline, Roo Code** 등에서 Anthropic 프로바이더를 선택하고 Base URL을 `https://api.siliconflow.cn/v1`로 지정하여 사용할 수 있습니다.

### 주의점 4: 심야 오프피크 50% 반값 할인
- **DeepSeek 전 모델**은 매일 **자정 00:00 ~ 02:00** 및 **20:00 이후** 입출력 모두 **50% 할인**이 적용됩니다.
- 심야 시간대에 배치 작업을 돌리면 16위안 바우처로 실질 32위안 이상의 효과를 누릴 수 있습니다!
