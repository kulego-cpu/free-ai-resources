# 텐센트 훈위안 (Hunyuan): 실제 무료 혜택과 개발자 안심 과금 차단 가이드

텐센트 클라우드의 독자적인 기반 모델 포트폴리오인 **텐센트 훈위안(Tencent Hunyuan)** 은 강력한 클라우드 백본망과 결합되어 많은 관심을 받고 있습니다. 그러나 개발자 커뮤니티에는 'Hunyuan-Lite 영구 무료'와 같은 부정확한 정보가 퍼져 있기도 합니다.

2026년 10월 최신 공식 문서와 과금 가이드를 토대로 텐센트 훈위안의 실제 무료 혜택과 안전한 연동 팁을 명확하게 정리해 드립니다.

---

## 1. 팩트체크: 독립된 'Hunyuan-Lite 영구 무료'는 없습니다

온라인상에 알려진 'Hunyuan-Lite 영구 무료' 정보는 사실과 다릅니다:

1. **❌ `hunyuan-lite`라는 독립 언어 모델은 없습니다**: 텐센트의 주력 추론 모델은 MoE 기반의 `hunyuan-a13b` 및 페르소나 대화 특화 `hunyuan-role-latest` 등입니다.
2. **유일하게 lite가 붙은 모델은 번역 특화형**: `hunyuan-translation-lite` (입력 백만 토큰당 1위안)는 번역 전용 유료 모델이며, 웰컴 패키지 차감 대상에 포함되어 있습니다.
3. **❌ 영구 무료 모델은 없습니다**: 모든 무료 혜택은 **개통일로부터 1년간 유효한 리소스 패키지** 형태로 지급되며 만료 시 소멸합니다.

---

## 2. 개통 시 실제로 지급되는 무료 패키지

영구 무료는 아니지만, 신규 개통 시 지급되는 초기 혜택은 매우 실용적입니다:

1. **8개 텍스트 모델이 공유하는 100만 토큰 패키지**:
   - **`hunyuan-a13b`**: MoE 구조(총 80B / 활성 13B) 주력 모델, 224K 장문 컨텍스트, 빠른 생각과 깊은 추론 전환(`/no_think`) 지원.
   - **`hunyuan-role-latest`**: 캐릭터 롤플레잉 및 생동감 있는 대화에 특화.
   - **`hunyuan-translation`**: 33개 언어 및 5개 소수민족 언어를 지원하는 번역 엔진 (WMT25 1위).
   - **멀티모달**: 시각 정보 분석용 `Tencent HY Vision 1.5 Instruct` 등.
2. **독립된 100만 임베딩 토큰**: `Hunyuan-embedding` 벡터 검색 전용 100만 토큰.
3. **이미지 생성 100회**: 상업용 '훈위안 생도' 50회 + 초고속 '문생도 경량판' 50회.

---

## 3. 핵심 안심 기능: 소진 시 자동 유료 전환 없음!

클라우드 AI를 테스트할 때 개발자들의 가장 큰 불안 요소는 무료 크레딧이 소진된 후 계정에 연결된 결제 수단으로 자동 과금되는 것입니다.

텐센트 훈위안은 이 부분에서 안전한 정책을 제공합니다:
> **🛡️ 공식 정책**: 기본 설정상 무료 리소스 팩이 모두 소진되거나 1년이 지나 만료되더라도, **텍스트와 이미지 모두 자동으로 종량제 후불 과금으로 전환되지 않습니다**!

잔액 부족 오류를 반환하며 즉시 호출이 멈추므로, 관리 콘솔에서 직접 후불 과금을 신청하지 않는 한 원치 않는 청구서가 발생하지 않습니다.

## 4. TokenHub 전환 현황 및 3단계 빠른 시작

현재 텐센트 클라우드는 모델 라인업을 차세대 **TokenHub** 플랫폼으로 점진 통합 중이며, 기존 콘솔 엔드포인트도 정상적으로 호출 가능합니다.

### 3단계 빠른 시작:

1. **로그인 및 실명 인증**:
   콘솔 접속:
   👉 [https://console.cloud.tencent.com/hunyuan](https://console.cloud.tencent.com/hunyuan)
   위챗 또는 QQ로 로그인 후 실명 인증을 완료합니다(카드 등록 불필요).
2. **서비스 개통 후 무료 팩 수령**:
   콘솔에서 '지금 개통'을 클릭하면 100만 토큰 및 이미지 생성 100회 무료 팩이 즉시 지급됩니다 (1년 유효).
3. **OpenAI 호환 클라이언트 연동**:
   - **Base URL**: `https://hunyuan.tencentcloudapi.com`
   - **API Key**: 콘솔에서 생성한 API Key (Bearer Token)
   - **모델명**: `hunyuan-a13b`
   - **연결 테스트**: FreeAI Dog의 '측활 및 디버깅 도구'에서 즉시 엔드포인트 지연 속도를 측정해 보세요!
