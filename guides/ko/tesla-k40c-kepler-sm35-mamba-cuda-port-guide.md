# 2만원대 Tesla K40c로 Mamba-1 구동하기: Kepler 아키텍처 수제 CUDA 연산자와 순전파 정밀도 검증

중고 거래 사이트를 둘러보면 13년 전 출시된 NVIDIA Tesla K40c가 배송비 포함 2만원 안팎에 거래되고 있습니다. 저렴한가요? 믿기 힘들 정도로 쌉니다.

하드웨어는 골동품 수준입니다. 2013년 발표된 Kepler 아키텍처, 칩셋 코드명 GK110B. 2,880개의 CUDA 코어를 탑재하고 PCIe 3.0 x16 인터페이스로 동작하지만, 연산 능력은 고작 sm_35에 머뭅니다. 수많은 업자들이 알루미늄 폐기물 취급하며 무게 단위로 처분하고 있습니다. 이런 카드로 최신 모델을 구동하려는 사람이 과연 존재할까요?

하지만 기판 위에는 온전한 12GB GDDR5 물리 VRAM이 실장되어 있으며, 대역폭은 288 GB/s에 달합니다.

주류 생태계는 오래전에 지원을 중단했습니다. PyTorch 사전 빌드 패키지는 sm_35 지원을 제거한 지 오래입니다. FlashAttention과 Triton 같은 최신 가속 라이브러리 역시 최신 아키텍처만을 전제로 작동합니다.

Reddit 커뮤니티 r/LocalLLaMA 게시글 번호 1xr97iz에서 흥미로운 시도가 공개되었습니다. 작성자는 소스코드 저장소와 A100 비교 검증 스크립트를 게시했습니다.

우리는 작성자의 접근 방식을 따라 실험실에 테스트 벤치를 꾸렸습니다. 코드는 정상 실행됩니다. 다만 FP32 순전파 연산에 한정됩니다. 속도가 느린 것은 거스를 수 없는 물리 법칙이지만, 저수준을 파고드는 과정은 매우 흥미진진합니다.

## 연산자 단절: 구형 칩에서 Triton이 작동을 거부하는 이유

K40c 환경에서 Triton을 사용하는 것은 불가능합니다.

Mamba-1의 핵심 연산자는 Selective Scan입니다. 공식 레퍼런스 구현은 OpenAI Triton 컴파일러가 생성하는 저수준 커널에 전적으로 의존합니다.

nvcc로 공식 코드를 빌드하려 하면 터미널에 PTX 타깃이 sm_35를 지원하지 않는다는 에러가 쏟아집니다. 중단. 컴파일은 그 자리에서 멈춰 섭니다.

Kepler 아키텍처에는 반정밀도 행렬 연산을 전담하는 Tensor Core 유닛이 없습니다. bfloat16 같은 최신 포맷 역시 sm_35에서는 대응하는 물리 레지스터 명령어를 찾을 수 없습니다. 공식 저장소 코드를 강제로 호출하면 커널 실행 실패 에러만 반환됩니다.

공식 코드에 매달려 봐야 답이 나오지 않습니다.

엔지니어링 해법은 명확합니다. Triton을 완전히 우회하여 순수 네이티브 CUDA C++로 Selective Scan 연산자 전체를 바닥부터 다시 작성했습니다. 커널 내부 연산은 단정밀도 부동소수점 FP32 레지스터 폴백을 거쳐 진행됩니다.

이 커스텀 커널은 Makefile 컴파일 타깃에 sm_75까지 일괄 지정되어 있습니다. 모든 아키텍처에서 매끄럽게 돌아갈까요? 필자는 K40c 카드만 보유하고 있어 sm_35 환경에서만 실측을 완료했습니다. Maxwell이나 Pascal 실물 카드는 수중에 없으므로, 검증되지 않은 호환성을 장담하지는 않겠습니다.

현재 Mamba-1 130M 모델의 순전파 추론은 안정적으로 완주됩니다. 반면 370M 모델의 긴 컨텍스트 부하 테스트는 아직 진행하지 않았습니다.

## 정밀도 정렬: 순전파 출력 최대 절대 오차 3.8e-06

정밀도 정렬은 순전파에서만 확인했습니다. 역전파는요? 검증하지 않았습니다.

동일한 가중치 파라미터, 시드값 42 고정, 입력 시퀀스 길이 512토큰 설정 조건에서 A100 레퍼런스 스크립트와 K40c 커스텀 커널의 각 레이어 출력 텐서를 순차적으로 로그에 기록했습니다.

기록된 최대 절대 오차는 3.8e-06이며, 제19번 SSM 레이어의 상태 출력 행렬에서 발생했습니다.

```text
[Layer 01] SSM output max_diff: 1.19e-07
[Layer 08] SSM output max_diff: 8.34e-07
[Layer 15] SSM output max_diff: 2.15e-06
[Layer 19] SSM output max_diff: 3.81e-06
[Layer 24] SSM output max_diff: 3.42e-06
```

역전파 연산이나 더 긴 컨텍스트에 대한 전방위 검증은 완료되지 않았으므로 성급한 결론은 유보해야 합니다.

다만 순전파 실측 수치가 증명하듯, 내부 FP32 누적 연산을 통해 Parallel Prefix Scan 재귀 과정에서 치명적인 부동소수점 절단 붕괴가 발생하지 않았음을 확인할 수 있습니다.

Reddit 원문은 r/LocalLLaMA 스레드 1xr97iz입니다. 작성자 본문에 코드 저장소와 레이어별 비교 코드가 기재되어 있습니다. 진위를 확인하려면 재가공된 글이 아닌 원문의 커밋 로그를 직접 열람하시기 바랍니다.

순전파 정밀도를 이 정도로 빈틈없이 유지했다는 점에서 커스텀 커널의 메모리 타일 스케줄링이 탄탄하게 구현되었음을 알 수 있습니다. 제대로 연산이 수행되는 것만으로도 충분한 기술적 성취입니다.

## 실전 구축 가이드: 패시브 방열판과 EPS 전원 케이블 주의사항

소프트웨어 연산자가 통과되었더라도 하드웨어 측면의 물리적 복병이 도사리고 있습니다.

첫 번째 난관은 방열입니다.

Tesla K40c는 서버 랙 전용 계산 카드입니다. 공장 출하 시 알루미늄 패시브 방열판만 장착되어 있으며 자체 쿨링 팬이 없습니다. 가격이 싸다고 일반 데스크톱 메인보드에 그냥 꽂으면 부팅 3분 만에 코어 온도가 90도를 돌파하며 전원이 차단됩니다.

덕트 개조 없이 구동할 수 있을까요? 불가능합니다.

3D 프린터로 제작된 전용 덕트를 구비하고 후면에 9733 규격의 고풍압 블로워 팬을 케이블 타이로 단단히 결속해야 합니다. 팬 전원은 반드시 독립된 12V 라인에 직결해야 하며, 거센 풍절음과 함께 풀로드 온도를 65도 이하로 묶어 둘 수 있습니다.

두 번째 난관은 전원 단자입니다.

K40c의 전원 포트는 CPU 규격의 EPS 8pin과 PCIe 6pin 조합입니다. 일반 PC 그래픽카드용 8pin 규격이 아닙니다. 파워서플라이 번들 GPU 케이블을 억지로 연결하면 12V와 접지 핀 배열이 완전히 반대이므로 부팅이 되지 않거나 전원부 단자가 타 버립니다. 설치 전 반드시 전용 변환 케이블을 준비하십시오.

소프트웨어 스택은 CUDA 11.8 드라이버와 패치가 적용된 PyTorch 2.7.1 조합을 권장합니다. 구형 하드웨어에는 군더더기 없는 미니멀 런타임 환경이 가장 안전합니다.

## 비용 대비 가치: 2만원으로 얻을 수 있는 본질

저수준 분석을 마친 후 냉정한 하드웨어 성능 현실을 마주해야 합니다.

일상적인 추론용 카드로 활용할 수 있을까요? 그런 환상은 버려야 합니다.

13년 전 레거시 칩셋이라 메모리 대역폭은 288 GB/s에 불과하며 전용 행렬 가속 장치도 없습니다. Mamba 모델 구동 시 텍스트 생성 속도는 극도로 느려 문장 하나를 출력하는 데 수십 초가 소요됩니다. 대화형 인터페이스를 띄워 두면 답답함에 창을 닫게 될 것입니다.

하지만 이 카드의 가치는 생성 속도에 있지 않습니다.

패키지 게임 한 편 가격으로 네이티브 CUDA 커널 개발을 지원하는 12GB 대용량 VRAM 장비를 확보할 수 있습니다.

상태 공간 모델의 수학적 기저를 직접 분해하고 싶은 학도에게도, 저비용으로 오프라인 실험 환경을 꾸리고 싶은 개발자에게도 훌륭한 하드웨어 분해실 역할을 해 줍니다.

최소한의 예산으로 커널 스케줄링과 메모리 분할의 정수를 체득하는 경험은 되팔이들에게 웃돈을 얹어 주는 것보다 훨씬 알찬 성취감을 선사할 것입니다.
