# iFLYTEK 스파크 라이트(Spark Lite): 보기 드문 '영구 무료 + 무제한 토큰' 국가지정 LLM

대다수 중국계 파운데이션 모델 제공업체가 '기간 한정 체험 크레딧(소진 후 즉시 유료 전환)' 정책을 펼치고 있는 가운데, iFLYTEK(커다쉰페이)의 **스파크 대모델(iFLYTEK Spark)** 은 개인 개발자들에게 놀라운 혜택을 지속적으로 제공하고 있습니다: **주력 경량 모델인 Spark Lite(모델 ID: `lite`)는 공식적으로 영구 무료(0원)이며, 전체 토큰 사용량에 제한이 없습니다(무제한 토큰)!**

더욱 편리한 점은, 플랫폼 가입 및 발급 절차가 매우 가볍다는 것입니다. **주민등록증/신분증 실명인증(KYC)이나 해외 결제 카드 등록이 전혀 필요 없으며**, 휴대폰 SMS 인증만으로 몇 초 만에 API Key를 발급받을 수 있습니다.

---

## 1. 공식 검증: Spark Lite는 정말 영구 무료인가?

'영구 무료'라는 문구를 보면 많은 개발자들이 숨겨진 비용이나 체험 후 강제 청구 함정을 의심하기 마련입니다.

iFLYTEK 공식 인터페이스 규격과 과금 체계를 정밀 검증한 결과는 다음과 같습니다:
1. **공식 문서 상 0원 명시**: Spark Lite(`lite`)는 경량 범용 언어 모델로 정의되어 있으며, 공식 가이드와 가격 정책 페이지에 '무료 이용 지원'으로 명시되어 있습니다. Xingchen MaaS 청구서 상에서도 파인튜닝만 유료이며, 표준 추론 호출 단가는 **백만 토큰당 0원**입니다;
2. **소멸성 바우처가 아닌 무제한 총량**: 매월 초기화되거나 일정 기간 후 소멸하는 체험 쿠폰과 달리, Lite 모델의 무료 혜택은 총량 상한선이 없습니다. 개인 비서, 챗봇, 자동화 스크립트의 영구적인 백업 모델로 제격입니다;
3. **MaaS 엣지 소형 모델 추가 지원**: 플랫폼에서는 추가로 **`Spark-X2.5-1.7B`(엣지 전용 소형 모델, 영구 무료, 1M 컨텍스트)** 및 **`Spark-X2.5-4B`(한시적 무료)** 모델도 함께 제공하고 있습니다.

## 2. 개발자가 알아야 할 4가지 주의사항 (Gotchas)

iFLYTEK 무료 API를 연동할 때는 다음의 엔지니어링 제약 조건을 고려해야 합니다:

1. **⚡ 2 QPS 속도 제한**:
   무료 플랜의 주된 제약 사항은 **계정당 2 QPS(초당 최대 2건의 요청, 약 120 RPM)** 입니다. 개인적인 일상 대화나 순차 작업에는 충분하지만, 멀티스레드로 과도한 동시 요청을 보내면 즉시 `11202`(초당 호출 초과) 오류가 반환됩니다.
2. **🌐 CORS 미지원 (백엔드 프록시 필요)**:
   스파크 API 게이트웨이에는 `Access-Control-Allow-Origin` 응답 헤더가 설정되어 있지 않습니다. 웹 프론트엔드 브라우저에서 네이티브 `fetch`로 직접 호출하면 브라우저 보안 정책에 의해 차단됩니다. **NextChat, ChatBox 등 데스크톱 클라이언트에서 직접 사용하거나, Node.js / Python 백엔드 프록시를 통해 호출하는 것을 권장합니다.**
3. **🛠️ Lite 모델의 기능적 한계**:
   Lite 모델은 스트리밍(SSE) 및 구조화된 JSON 출력을 완벽 지원하며, 컨텍스트는 8K 입력(최대 4K 출력)입니다. 다만 **실시간 웹 검색 플러그인과 Function Calling(도구 호출)은 지원하지 않습니다.** 함수 호출이 필요한 경우 유료 플래그십인 `4.0Ultra` 모델을 사용해야 합니다.
4. **🔑 간편한 인증: APIPassword를 Bearer Token으로 직접 사용**:
   iFLYTEK은 현재 표준 OpenAI 포맷을 지원합니다. 과거의 복잡한 WebSocket HMAC-SHA256 서명 없이, HTTP 요청 헤더에 `Authorization: Bearer <사용자의 APIPassword>`를 전달하기만 하면 즉시 정상 호출됩니다!

## 3. 3단계 가입 및 클라이언트 설정 가이드

1. **전화번호 인증으로 콘솔 로그인**:
   iFLYTEK Spark 공식 콘솔 링크에 접속합니다:
   👉 [https://console.xfyun.cn/services/bmx1](https://console.xfyun.cn/services/bmx1)
   휴대폰 번호로 SMS 인증번호를 받아 로그인합니다 (신분증 업로드나 안면인식 불필요).
2. **대모델 애플리케이션 생성 및 인증정보 확인**:
   애플리케이션 목록에서 새 앱을 생성한 뒤, 'HTTP 인터페이스 호출 자격' 항목에서 **APIPassword**를 복사합니다.
3. **OpenAI 호환 클라이언트 연동**:
   - **Base URL**: `https://spark-api-open.xf-yun.com/v1`
   - **API Key**: 복사한 `APIPassword`
   - **모델명**: `lite`
   - **지연 시간 테스트**: FreeAI Dog의 '헬스체크 및 디버그 도구'에서 바로 테스트해 보세요 (보통 150ms 내외로 매우 빠릅니다)!
