## 三、 快速接入与代码实战（兼容 OpenAI SDK）

百川智能 API 完全遵循 OpenAI 接口协议规范，你只需将 `baseURL` 指向 `https://api.baichuan-ai.com/v1`，即可通过官方 OpenAI SDK 快速调用。

### Python 接入实测

```python
from openai import OpenAI

# 初始化百川智能客户端
client = OpenAI(
    api_key="your_baichuan_api_key_here",
    base_url="https://api.baichuan-ai.com/v1"
)

# 发起聊天请求（推荐性价比之王 Baichuan4-Air）
response = client.chat.completions.create(
    model="Baichuan4-Air",
    messages=[
        {"role": "system", "content": "你是由百川智能训练的 AI 助手，请用简洁准确的中文回答。"},
        {"role": "user", "content": "请用 3 点总结百川智能大模型的核心优势。"}
    ],
    temperature=0.3,
    stream=True
)

# 流式输出响应
for chunk in response:
    content = chunk.choices[0].delta.content or ""
    print(content, end="", flush=True)
print()
```

### cURL 快速测试

```bash
curl -X POST "https://api.baichuan-ai.com/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "Baichuan4-Air",
    "messages": [
      {"role": "user", "content": "你好，请介绍一下你自己！"}
    ],
    "temperature": 0.5
  }'
```

## 四、 开发者必须了解的 5 大工程避坑指南

结合团队对百川智能 API 的实测，开发者在集成时务必注意以下工程细节：

### 1. 严格 5 RPM 频率限制（最常见踩坑点）
百川智能免费体验层对未升级账号设置了每分钟 5 次请求（5 RPM）的速率限制。如果在客户端循环发起并发请求，将迅速触发 `HTTP 429 Too Many Requests`。
> **工程应对**：本地开发和自动化测试时，务必在请求队列中加入至少 12 秒的间隔等待，或采用指数退避重试（Exponential Backoff）。

### 2. 80 元代金券 3 个月有效期限
新用户领取的 80 元体验金有效期为 **90 天**。到期后账户中未消耗完的赠送金将自动过期清零，无法顺延。
> **工程应对**：建议在完成注册后优先安排核心业务原型验证，避免将代金券闲置至过期。

### 3. 联网搜索插件（Web Search）额外计费规则
百川智能支持原生的实时搜索增强插件，但搜索功能并非完全免费，每次调用通常加收约 ¥0.03 的搜索服务费。
> **工程应对**：如果纯测试基础语言理解或追求零额外支出，请保持 `tools` 或搜索插件处于关闭状态。

### 4. CORS 跨域为 Origin 精确回显机制
实测百川智能端点的 OPTIONS 预检请求返回的 `access-control-allow-origin` 是精确匹配客户端请求头中的 Origin，而非通配符 `*`。
> **工程应对**：在网页端直接直连 API 时，必须规范携带正确的 Origin 请求头。若在纯静态前端无后端模式下遇到跨域问题，建议通过轻量反向代理统一转发。

### 5. 纯预付费机制无自动扣费风险
与海外部分绑定信用卡后额度耗尽自动按量扣费的厂商不同，百川智能采用标准预付费模式。当 80 元代金券耗尽且未主动充值时，API 将直接返回 `HTTP 402 Payment Required`（或提示余额不足），**完全不存在信用卡被突发大额扣款的风险**，开发者可以安心测试。
