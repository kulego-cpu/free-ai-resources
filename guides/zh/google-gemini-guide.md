## 一、 准备工作

1. 一个普通的 Google 账号（Gmail 邮箱即可）；
2. 能够访问 Google 服务的海外网络环境。

---

## 二、 3 步获取你的专属 API Key

### 第一步：访问 Google AI Studio 控制台
打开浏览器，访问官方直达链接：
👉 [https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)

如果尚未登录 Google 账号，根据提示输入邮箱密码完成登录。首次进入时勾选同意服务协议。

### 第二步：创建 API 密钥
进入控制台页面后：
1. 点击左上角蓝色的 **「Create API key」** 按钮；
2. 在弹出窗口中选择 **「Create API key in new project」**（在新建项目中创建）；
3. 系统会在 2 秒内生成一串以 `AIza` 开头的专属密钥字符串。

### 第三步：复制并保存
点击密钥旁边的 **「Copy」** 图标。

> [!IMPORTANT]
> **安全提醒：**
> API Key 相当于你在 Google 的身份证，请妥善保存在本地记事本中，切勿公开发布到 GitHub 或社交平台。
