## 30秒极速上手：如何无痛创建你的 Groq API Key

与其他动辄要求绑定海外信用卡、验证海外手机号的大厂不同，Groq 目前的免费层门槛是全网大厂中最低的：

1. **访问控制台**：打开浏览器访问 [Groq Console](https://console.groq.com)；
2. **一键授权登录**：直接点击 **`Continue with Google`** 或 **`Continue with GitHub`** 完成一键授权登入（注意：Groq 仅支持第三方快捷授权，不提供传统邮箱账号密码注册）；
3. **免手机号/免绑卡**：**完全不需要海外手机号接收短信验证码，完全不需要绑定信用卡**，亦无 7/14/30 天试用期倒计时，永久长期有效；
4. **生成密钥**：在左侧导航栏找到 **`API Keys`**，点击右上角 **`Create API Key`**；
5. **命名并保存**：给 Key 起个名字（如 `My-Groq-Free`），点击生成后立即复制保存这串 `gsk_...` 开头的字符串。

> ⚠️ **温馨提示**：Key 只会在创建时完整显示一次，请务必随手存入你的密码管理器或备忘录。

## 客观曝光：Groq 的核心硬伤与避坑指南

天下没有完美的免费午餐。如果你想用好 Groq，就必须清楚它的规则与天花板在哪里，避免在错误的项目上踩坑崩溃：

### 1. 致命误区：别被 14,400 误导，文本主力其实是 1,000 RPD
网上许多过时或不负责任的教程宣称“Groq 每天免费 14,400 次”，**大错特错！**
* **实测真相**：14,400 次仅仅是针对极轻量安全防护模型（Prompt Guard）的配额！真正的文本主力（`openai/gpt-oss-120b`、`qwen3.8-27b` 等）每天只有 **1,000 次请求（RPD）**。
* **分级频控**：每分钟上限为 **30 次（RPM）** 与 **8,000 TPM**。如果脚本在 10 秒内并发打满 30 次请求，哪怕当天 1,000 次额度还剩 900 多次，也会立刻触发 HTTP 429 频控报错。请务必在客户端配置队列限速！

### 2. 升级通道关闭：无需费心折腾外币信用卡
由于全球高并发算力极其紧张，Groq 官方目前已经**明确关闭了绑卡升级 Developer Tier 的通道**（官方明确标注 Developer tier upgrades are temporarily unavailable due to high demand）。
* **避坑建议**：大家完全不需要为了升级去费劲绑定外币信用卡，安心使用默认的免费层（Free Tier）即可。

### 3. 网络环境门槛：中国大陆需代理，但前端 CORS 完全放行
* **CORS 友好**：Groq 官方 API 的响应头完全放行了跨域（`Access-Control-Allow-Origin: *`），像 NextChat、自建 API 测试器或 Chrome 插件直连没有任何前端阻碍；
* **区域拦截**：但其底层走 Cloudflare 基础设施，**中国大陆 IP 会被直接拦截拦截阻断**。大陆用户调试需自备海外网络节点，或者通过 Cloudflare Worker 自建轻量反向代理转发。

### 4. 触发 429 报错如何优雅自愈？
Groq 免费层没有任何信用卡扣费风险，超额只返回 HTTP 429。
* 响应头会清晰附带 `retry-after: 2`（代表等待 2 秒即可继续），以及重置倒计时；
* 此外 **Cache 命中（Prompt Cache）的 Token 是完全不计入 TPM/TPD 配额的**，对于结构固定、前缀重复的 Prompt 极其划算。
