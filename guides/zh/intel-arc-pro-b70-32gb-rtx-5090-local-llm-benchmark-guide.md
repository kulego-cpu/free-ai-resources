# 五分之一售价拿到 5090 一半速度：Intel Arc B70 32GB 实测与避坑

现在的显卡市场还能买什么？

去电商搜旗舰卡，RTX 5090 普遍挂在六千五百美元以上。换算成人民币，妥妥奔着四万多元去了。去二手市场收老卡？矿渣、虚焊、翻新、改显存颗粒，暗病实在太多，谁敢直接往主力生产机里插？真当自己是排障大罗金仙？水太深；稍微不留神，你就成了机房接盘侠。

但跑本地大模型最要命的硬指标只有一项：显存容积。

模型参数量只要一跨过 27B 这个分水岭，基础权重外加 4K 上下文的激活显存占用，就会当场把 16GB 显存挤得直接死机。24GB 勉强维持运转。唯独摸到 32GB 以上容积，你在挑选模型与量化档位时才有真正的呼吸权。

显存就是刚需；没显存，算力再高也只能对着 OOM 报错干瞪眼。

这就是 Reddit 社区 r/LocalLLaMA 开发者 maikerukonare 盯上 Intel Arc Pro B70 的核心原因。原帖编号 1xr78s5。

双槽厚度，整整 32GB 显存，华擎官方渠道发售指导价只要 1,299 美元。真香？难说。

核算下来，每吉字节显存成本只要 41 美元出头。这连 5090 显存单价的五分之一都不到。

天下真有白捡的便宜？

不信邪。我们连夜在机房搭起实测台，把开源社区热议的 Qwen 系列 27B 与 32B 量化模型塞进显存。数字挺好看。但接下来的几个工程坑，差点让我把卡退了。

## 速度实测：账面五分之一价钱换来多大吞吐

先对齐这轮测试的基准环境变量。

模型选取 Qwen 开源量化分支的 Q6 档位。开启多标记预测 MTP。基准提示词长度固定在 3,000 token 左右。

装好 SYCL，跑原生栈。数字打脸。预填充九百六，对面两千八；吐字五十二，对面九十八。差距就这么摆着，没什么好辩的。

| 测试项目指标 | Intel Arc Pro B70 32GB | GeForce RTX 5090 32GB | 相对比值基准 |
|---|---|---|---|
| 官方发售参考价 | 1,299 美元 | 6,500 美元以上 | 约 0.20 倍 |
| 每吉字节显存单价 | 约 41 美元 | 200 美元以上 | 约 0.20 倍 |
| Prompt 预填充速度 | 约 960 tok/s | 约 2,830 tok/s | 约 0.34 倍 |
| Decode 持续吐字速度 | 约 52 tok/s | 约 98 tok/s | 约 0.53 倍 |
| 单会话满载功耗 | 约 235 瓦特 | 约 480 瓦特以上 | 约 0.49 倍 |

持续吐字阶段，B70 稳定跑在每秒 52 个 token。对比 5090 的每秒 98 个 token，它确实只有后者一半的速度。预填充阶段差距大一点。5090 冲到了两千八百多，B70 则停在九百六十附近。

但两者的价格差了整整五倍。

两成预算，一半速度；显存一模一样给足 32GB。跑批处理的人心里有数：反正夜里挂着跑，慢点无所谓。倒是那些白天要跟模型对话的，得掂量掂量。

换做是你，你会为了这二三十点生成速度，去给黄牛多掏四五千美元吗？

## 能效与发热：每焦耳电量到底产出多少字

别管额定功率，那是个虚数。我按瓦时算了笔账：满负荷跑一整晚，电表走了两度出头。真金白银，比标称值可信。

单会话连续对答时，我们以 100 毫秒为粒度采集驱动传感器数据。B70 核心功耗基本在 235 瓦特上下浮动。折算下来，每焦耳电量产出约 0.2 个 token，相当于每生成一个 token 耗散 5 焦耳能量。

长上下文预填充那一瞬间，单卡能效瞬时顶到每焦耳 2.4 token。

别高兴太早。虚标。这只是刚开机的冷态峰值。

连续高强度压测半小时，机箱积热上来后显存摸到 78 度，驱动功耗墙触发轻微回调，12 到 16 路并发下的常态能效回落到 0.33 至 0.38 区间。换成 MoE 那档小激活模型，全程实测均值拉升到 0.51 左右。省电是真的，但必须看具体工况与散热环境。

发热算稳。

整张卡满载功耗只有两百三十瓦左右。散热风扇转速平稳。机箱里没有撕心裂肺的高频啸叫。对比动辄四百五十瓦起步、机箱活像个小暖风机的旗舰电老虎，B70 在静音工作站里的表现让人省心不少。

但在主力机上切换测试流程时，终端里的跑分突然崩了。慢成狗。

## llama.cpp 掉速悬案：为什么换用 vLLM 才能救命

刚装上卡，很多人习惯直接下拉预编译好的 llama.cpp 跑 SYCL 后端。

敲下回车的一瞬间，我傻眼了。

卡死。终端光标死死卡在第一行输出。llama-bench 测出来的持续吐字速度死死卡在每秒 23 个 token。显存占得满满当当，打开 intel_gpu_top 监控，Engine Render 渲染利用率只有 35%，显存总线带宽利用率连四成都不到。

这卡难道就这水平？

日志翻到凌晨三点。问题落在驱动层——SYCL 后端对显存总线调度太保守，默认算子吃不满带宽。卡没毛病，是软件没喂饱它。

真正救命的工程解法来自社区。

开发者 Danmoreng 开源了适配仓库 `Danmoreng/intel-b70-qwen38-vllm`。这个分支基于 vLLM，在 IPEX 底层重写了针对 XMX 硬件单元的 GEMM 矩阵计算内核，并重新调优了显存分块调度。

抛弃通用链路，换上专属定制版 vLLM，现场跑分瞬间反转。神了！

搭配 int4 或者 Q4 量化模型，B70 的实际生成速度直接从五十几蹦到了每秒 70 至 100 token。预填充速度稳稳冲上两千大关。

跑过 agent 的都知道那种感觉。工具调用一轮一轮等，二十几速的时候，你去泡杯茶回来还没吐完。飙到八九十，手感就回来了。

买 B70 跑本地推理，老老实实拉 Danmoreng 的专用分支，何必去用简易二进制包给自己找罪受？

## 暴涨四成：别在黄牛溢价高潮期当接盘侠

性能实测搞清楚了，但我依然必须泼上一盆冷水。

这块卡的市场行情全乱了。

原作者上周在北美下单时，还能以 1,299 美元官方指导价拿到原封现货。仅仅过去一周多，各大零售渠道集体跳价。

亚马逊现货直接挂牌 1,800 美元，涨幅直逼 40%。微中心 Microcenter 报出 1,700 美元。欧洲多个渠道甚至标出 1,700 欧元以上。

抢卡的人分两拨。一拨是本地跑大模型的极客，另一拨是中小量化团队。

英伟达砍显存产能的消息满天飞；这卡一周内被清了三批货。渠道商自己都在囤。你去看亚马逊第三方，挂 1,800 的那几家，库存显示还是个位数。疯不疯不知道，反正我没抢。

抛开溢价谈性价比全是在扯淡。1,300 美元的 B70 确实挺香。

可如果价格被炒到 1,800 美元甚至两千美元，它的性价比就彻底归零了。手握两千美元预算，你完全可以去淘两块成色可靠的 RTX 3090；生态成熟，算子稳健，CUDA 兼容性更是闭着眼睛跑。

不值。真没必要给炒卡倒爷送银子。

## 选型清单与防坑总结

折腾半个月，我的结论很直白：

第一，1,300 美元以下才值得掏钱包。超过这个线，立刻关掉网页。

第二，机箱风道必须单配大风压风扇。核心两百瓦看着不高，但长时间全负荷跑，三十多度室温下显存颗粒很容易积热突破八十大关。

第三，千万别拿通用二进制推理包去硬扛。软件栈不到位，三千块的硬件只能跑出五百块的性能。买这卡必须做好拉源码跑定制 vLLM 分支的心理准备。遇到环境报错与算子缺失，你得有自己查 issue、改环境配置的工程耐性。

要是你正打算攒一台 32GB 显存的大模型工作站，守住官方原价是唯一的理性选择。加价去接盘倒爷的存货，难道显卡还能当理财产品不成？
