# 百元 Tesla K40c 跑通 Mamba-1：Kepler 架构手写 CUDA 算子与前向对齐实录

二手平台上搜一圈，十三年前发布的英伟达 Tesla K40c 只要一百一十块钱包邮。便宜？真便宜。

硬件很老。2013 年发布的 Kepler 架构，核心代号 GK110B。内建 2880 个 CUDA 核心，走 PCIe 3.0 x16 接口；计算能力仅为 sm_35。很多卖家直接当拆机废铝论斤称；真有人买来跑模型？

但它的 PCB 板上，焊着足额 12GB 的 GDDR5 物理显存，带宽达 288 GB/s。

主流生态早就砍了适配。PyTorch 预编译包不再支持 sm_35。FlashAttention 和 Triton 更是起步就要求现代架构。

Reddit 社区 r/LocalLLaMA 原帖编号 1xr97iz。作者放出了代码仓库和 A100 对照脚本。

我们顺着原作者思路在机房搭了个测试台。代码能跑，但只保了 FP32 前向计算；慢是物理现实，但底层的折腾过程非常有意思。

## 算子断代：为什么 Triton 在老架构上直接罢工

Triton 这条路在 K40c 上走不通。

现代 Mamba-1 的核心算子是 Selective Scan 选择性扫描。官方原生实现重度依赖 OpenAI Triton 编译器生成的底层代码。

拿 nvcc 去编官方实现，终端直接报 PTX 目标不支持 sm_35，当场吐出一长串编译错误。卡死。终端直接挂起。

Kepler 硬件层没有专门处理半精度的 Tensor Core 单元；甚至连 bfloat16 这种现代格式，在 sm_35 上也找不到对应的物理寄存器指令。强行调用官方仓库，显卡只会报出内核启动失败的警告。

死磕没意义。

工程解法直截了当：彻底绕开 Triton，用纯原生 CUDA C++ 重新手写全套 selective scan 核心算子。计算走单精度浮点 FP32 寄存器回退。

这套内核在 Makefile 编译目标里一路配到了 sm_75；真能跨架构全通？但我手里只有 K40c，实测仅在 sm_35 架构下跑通。手头没有 Maxwell 和 Pascal 显卡，对应架构我没测，不做无凭据的保证。

目前 Mamba-1 130M 规格的前向推理能稳定跑通，370M 还没做长序列压力测试。

## 精度对齐：前向输出最大绝对误差 3.8e-06

对齐只做了前向；反向呢？没做。

同一份权重、固定随机种子 42、输入长度固定为 512 的序列，A100 参考脚本和 K40c 手写内核逐层打印输出张量。

实测最大绝对差 3.8e-06，落在第 19 层 SSM 的输出矩阵上。

```text
[Layer 01] SSM output max_diff: 1.19e-07
[Layer 08] SSM output max_diff: 8.34e-07
[Layer 15] SSM output max_diff: 2.15e-06
[Layer 19] SSM output max_diff: 3.81e-06
[Layer 24] SSM output max_diff: 3.42e-06
```

反向传播和更长上下文的序列还没做全面验证，先别急着下什么结论。

不过前向推理的数据摆在这里：FP32 内部累加保证了递归前缀和 Parallel Prefix Scan 没发生严重的浮点截断崩溃。

Reddit 原帖是 r/LocalLLaMA 的 1xr97iz，作者正文里贴了代码仓库和 A100 逐层对比脚本。要复核请直接去翻原帖和 commit 记录，别看二次转述。

精度咬得这么紧，手写内核的分块调度确实扎实；能跑就算成功，还要啥自行车？

## 垃圾佬实操：被动散热与 EPS 供电线序避坑

软件算子调通了，硬件层面的暗坑照样能让人折腾脱层皮。

第一道坎是散热。

Tesla K40c 是机架服务器卡。原厂只有被动散热铝挤鳍片，压根没有主动风扇。新手要是贪便宜买回来直接插家用主板，开机三分钟核心温度飙破九十度，整机直接断电黑屏。

不改风道能行吗？不行。

花十五块钱买个 3D 打印专用导风罩。尾部用扎带固定一只 9733 规格的大风压涡轮蜗牛风扇。风扇务必接 12 伏独立供电；伴随着巨大的风噪，满载温度才能压在 65 度以内。

第二道坎是供电接口。

K40c 的供电口是 CPU 规范的 EPS 8pin 配合 PCIe 6pin。它不是家用显卡的 8pin 接口。拿电源自带的显卡线硬插，地线与 12 伏引脚定义完全不同，轻则开不了机，重则当场烧毁电源端子。买卡前务必备好合规的转接线。

软件编译栈推荐锁定在 CUDA 11.8 驱动配合打过补丁的 PyTorch 2.7.1。老硬件经不起花哨包装，精简的运行时环境最稳当。

## 真实账本：一百块钱到底买到了什么

聊完底层折腾，必须面对冷酷的算力现实。

拿来当日常推理卡？趁早断了念想。

十三年前的老芯片，显存带宽只有 288 GB/s，也没有专用矩阵硬件加速；跑 Mamba 模型的实际吐字速度极其缓慢，几十秒才能吐完一句话。拿它跑交互对话？你会等到关窗口。

但它的价值根本不在于拼吞吐。

花上一张正版游戏的钱，你就能拿到 12GB 的物理大显存。这是一张支持原生 CUDA 算子开发的高可靠性实验硬件。

不管是深入理解状态空间模型的数学底层，还是低成本搭建离线验证环境，它都是一台绝佳的硬件解剖台。
